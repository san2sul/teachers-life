교사의 생활 도움말

출석·시간표·연락·일정·수행평가 서명·관찰 기록을 한 앱에서. 처음 쓰는 분은 1번부터 차례로 읽어 보세요.

목차
    찾는 내용이 없습니다. 다른 낱말로 찾아보세요.

    1. 처음 시작하기

    앱 열기와 설치

    1. 안내받은 앱 주소(예: https://○○○.github.io/teachers-life/)를 엽니다. 아이폰은 Safari, 안드로이드는 Chrome으로 여세요.
    2. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
      • 아이폰: 아래 공유 버튼(□↑) → 홈 화면에 추가
      • 안드로이드: 오른쪽 위 ⋮ → 앱 설치 또는 홈 화면에 추가
      • 컴퓨터 크롬: 주소창 오른쪽의 설치 아이콘(모니터 모양) → 설치
    3. 한 번 연 뒤에는 인터넷이 없어도 열립니다. (문자·전화·메일·동기화는 인터넷이 필요합니다)

    화면 구성

    아래 메뉴하는 일
    시간표학기별 시간표, 수업 칸을 누르면 출석 체크·수업 메모, 일정·알림
    출석날짜·시간별 출석 체크, 잠금, 학생 관찰 기록
    연락결석 학생, 골라서 연락(문자·전화·이메일), 교사·교직원 연락
    할 일일정과 과제·면담을 날짜별로 모아 보기, 알림 확인
    평가·통계수행평가 점수 보내기와 학생 자필 서명, 출석 통계
    설정구글 로그인·기기 연동, 학급·명단·연락처, 공유, 백업, 앱 정보
    어느 화면에서든 오른쪽 위 ? 도움말을 누르면 그 화면의 설명으로 바로 옵니다.

    자료는 어디에 저장되나요?

    입력한 모든 자료는 쓰고 있는 휴대폰(또는 컴퓨터)의 브라우저 안에 저장됩니다. 앱을 만든 사람의 서버로는 아무것도 가지 않습니다. 구글 로그인을 켜면 같은 자료가 내 구글 드라이브의 앱 전용 숨김 폴더에도 저장되어 다른 기기와 맞춰집니다.

    브라우저의 ‘인터넷 사용 기록·사이트 데이터 삭제’를 하면 기기 안의 자료가 지워질 수 있습니다. 구글 연동을 켜 두거나 가끔 설정 → 백업 · 초기화 → 백업 파일 저장을 해 두세요.

    2. 휴대폰과 컴퓨터(크롬)에서 함께 쓰기

    같은 구글 계정으로 로그인하면 휴대폰 앱과 컴퓨터 크롬에서 같은 자료로 일합니다. 예를 들어 컴퓨터에서 엑셀로 명단을 올리면 휴대폰에도 들어오고, 휴대폰에서 한 출석 체크는 컴퓨터에서도 보입니다.

    처음 연결하기

    1. 컴퓨터 크롬에서 앱 주소를 열고 설정 → 구글 로그인 · 기기 연동 → Google 계정으로 로그인
    2. 구글 창에서 계정을 고르고, 권한 화면의 ‘Google Drive에서 자체 구성 데이터 확인·생성·삭제’에 체크 → 계속
    3. 휴대폰 앱에서도 같은 계정으로 똑같이 로그인합니다.
    4. 두 기기 모두 자료가 있으면 ‘처음 연동하기’ 창이 뜹니다. 보통은 두 자료 합치기를 고르세요.

    평소 쓰는 법

    • 내용을 바꾸면 몇 초 뒤 자동으로 올라가고, 다른 기기는 앱을 열거나 다시 볼 때 받아옵니다.
    • 화면 오른쪽 위 표시: 동기화됨 / 올릴 내용 있음 / 연동하려면 누르기
    • 구글 보안 정책상 로그인은 약 1시간 유지됩니다. ‘연동하려면 누르기’가 보이면 한 번 누르면 됩니다.
    • 바로 맞추려면 설정 → 지금 동기화
    • 두 기기에서 같은 내용을 동시에 고치면 지금 쓰는 기기 쪽을 우선하고 나머지는 합칩니다. 잘못되면 설정 → 백업 · 초기화 → 불러오기 전으로 되돌리기
    • 보고 있는 학급·화면, 할 일 보기 설정은 기기마다 따로입니다.

    계정 추가·전환

    설정 → ＋ 다른 구글 계정 추가 · 전환. 계정마다 자료가 따로 보관되어, 개인 계정과 학교 계정의 자료가 섞이지 않습니다. 원래 계정으로 돌아가려면 ‘○○(으)로 전환’을 누르세요.

    아이폰 홈 화면 앱에서 로그인 창이 닫히지 않으면 Safari에서 앱 주소로 열어 로그인하세요. 학교 구글 계정은 관리자가 막아 두었을 수 있으니 개인 계정을 권합니다.

    3. 자료 올리기 · 내려받기

    올리기 (가져오기)

    무엇을어디서
    학생 명단·전화번호·이메일설정 → 학생 명단 · 연락처 → 일괄 입력 · 파일 올리기 (엑셀·CSV 파일 또는 붙여넣기)
    수업 교사 / 교직원 연락처각 칸의 일괄 입력 · 파일 올리기
    수행평가 점수 전표평가·통계 → 전표 올리기
    백업 파일·공유 파일(.json)설정 → 백업 · 초기화 → 백업 파일 불러오기
    컴퓨터에서 아무 파일이나앱 화면 위로 파일을 끌어다 놓기 → 학생·수업 교사·교직원 중 고르면 미리보기
    올리기 전에 항상 미리보기가 나옵니다. ‘추가하기’는 지금 목록에 더하고, ‘목록 바꾸기’는 지금 목록을 지우고 바꿉니다. 제목 줄·‘예시’ 줄은 자동으로 건너뛰고, 엑셀에서 빠진 휴대폰 번호 앞자리 0도 되살립니다.

    양식 내려받기

    • 명단 양식: 설정 → 명단 가져오기 · 입력 양식 또는 일괄 입력 창의 양식 받기(엑셀·CSV)
    • 수행평가 전표 양식: 평가·통계 → 전표 양식 받기 (학급 명단이 미리 들어간 양식 가능)

    내려받기 (내보내기)

    파일어디서
    전체 백업(.json)설정 → 백업 · 초기화 → 백업 파일 저장
    출석 통계(엑셀·메일)평가·통계 → 출석 통계
    서명 들어간 수행평가 전표(엑셀·PDF)평가 화면의 엑셀 파일 / PDF로 인쇄
    서명 현황(엑셀)평가·통계 → 서명 현황 모아 보기 → 엑셀로 받기
    관찰 기록(엑셀)출석 → 관찰 기록 → 관찰 기록 엑셀로 받기
    일정(캘린더 파일)시간표 → 일정·알림 → 앞으로의 일정 캘린더 파일로 보내기

    휴대폰에서는 공유 창이 열리면 카카오톡·메일·드라이브 등을 고르면 되고, 컴퓨터에서는 다운로드 폴더에 저장됩니다.

    4. 학급 · 명단 · 연락처 (설정)

    학급 만들기·바꾸기

    1. 출석 화면 맨 위 학급 이름을 누르면 학급 목록이 열립니다.
    2. 새 학급 이름을 넣고 추가. 학급을 누르면 그 학급으로 바뀝니다. ‘수정’에서 이름 바꾸기·복사·삭제

    학생 추가·수정

    • 설정 → 학생 명단 · 연락처: 학번·이름·전화번호·이메일을 넣고 ‘학생 추가’
    • 목록의 학생을 누르면 고치기, 다른 학급으로 옮기기, 삭제. 학번을 바꾸면 출석·관찰 기록도 함께 옮겨집니다.
    • 많으면 ‘일괄 입력 · 파일 올리기’로 한 번에 넣으세요.

    수업 교사 · 교직원

    수업 교사는 학급마다, 교직원은 모든 학급이 같이 씁니다. 이름을 누르면 수정·삭제할 수 있습니다.

    앱 배포 · 명단 공유

    • 앱 보내기 / QR 코드: 다른 선생님에게 앱 주소와 설치 안내만 보냅니다(명단 없음).
    • 명단 골라 공유: 학급·학생 명단·학생 연락처·수업 교사·교직원을 골라 링크·파일·QR로 보냅니다. 받는 분은 링크를 열면 로그인 없이 들어갑니다.
    연락처를 넣은 링크는 받은 사람 누구나 번호를 볼 수 있습니다. 같은 학교 선생님에게만 보내세요. 관찰 기록과 수행평가는 공유 링크에 들어가지 않습니다.

    4-1. 적용 기간 (학년도 · 학기)

    학급, 학생 명단·연락처, 수업 교사, 교직원 연락처, 평가는 학년도·학기별로 따로 관리됩니다. 지난 학기 자료는 지워지지 않고 남아 언제든 다시 볼 수 있습니다.

    1. 설정 → 적용 기간 (학년도 · 학기)에서 학년도와 학기를 고르면 그 기간의 학급·명단·연락처·평가가 출석·연락·평가·설정 화면에 보입니다.
    2. ‘등록된 기간’ 버튼을 누르면 그 기간으로 바로 바뀝니다. 출석 화면 맨 위 학급 이름 아래에도 지금 기간이 보입니다.
    3. 새 학기·학년도가 되면 ＋ 새 학기 · 학년도 시작하기:
      • 새 학년도·학기를 고르고, 복사해 올 기간과 학급을 고릅니다.
      • 학생 명단, 학생 연락처, 수업 교사, 교직원 연락처 중 복사할 것을 체크합니다. 출석·관찰 기록은 복사하지 않습니다.
      • 학년이 바뀌면 복사한 뒤 학급 이름·학번을 고치거나 명단을 새로 올리세요.

    설정할 학급 고르기

    설정 화면의 설정할 학급은 처음에 출석 화면에서 고른 학급입니다. 다른 학급을 고르면 출석 화면 학급을 바꾸지 않고도 그 학급의 이름·문자 문구·학생 명단·연락처·수업 교사를 고칠 수 있습니다. 노란 안내의 ‘출석 화면 학급으로’를 누르거나 다른 화면으로 가면 원래 학급으로 돌아갑니다.

    5. 출석 체크

    1. 출석에서 날짜를 고르고 ＋ 출석 체크 시작(또는 ＋ 체크 추가). 지금 시간으로 체크가 생기며 하루 몇 번이든 됩니다.
    2. 학생 줄을 누르면 출석 ↔ 결석이 바뀝니다. ‘전원 출석’·‘전원 결석’도 있습니다.
    3. 체크마다 시간과 이름(예: 출발 전)을 바꿀 수 있습니다.
    4. 시간표의 수업 칸을 누르면 그 수업의 출석 체크가 바로 열립니다.

    잠금 · 잠금 해제 (5.4)

    • 체크를 마치면 잠그기를 누르세요. 잠긴 체크는 학생 줄을 눌러도 바뀌지 않고, 전원 출석·결석·삭제·시간 수정도 막힙니다. 위 시간 버튼에 🔒이 붙습니다.
    • 고쳐야 하면 잠금 해제 → 한 번 더 확인.

    6. 학생 관찰 기록

    1. 출석 → 관찰 기록으로 바꿉니다.
    2. 기록 날짜를 고릅니다. 고르지 않으면 오늘 날짜로 기록됩니다. 옆에 그날 기록 횟수와 누적 횟수가 보입니다.
    3. 빠른 체크: 위 항목(예: 질문함)을 누른 뒤 학생 이름을 누를 때마다 기록됩니다(×2, ×3…). 잘못 눌렀으면 아래 ‘되돌리기’. 항목을 다시 누르면 선택이 풀립니다.
    4. 학생 기록 창: 학생 줄의 ‘기록’(또는 항목 선택 없이 이름)을 누르면 태도·역량·특성 체크와 메모를 적습니다. 아래에 누적 집계와 지난 기록이 보입니다.
    5. ‘누적 기록 복사’로 세부능력 및 특기사항 작성에 붙여 넣고, ‘관찰 기록 엑셀로 받기’로 학생별 누적·날짜별 기록을 받습니다.
    6. ‘항목 편집’에서 우리 과목에 맞게 항목을 더하거나 지웁니다. ●을 누르면 좋음(초록)·보통·아쉬움(빨강)이 바뀝니다.

    학생 이름 아래의 누적 n회 · n일은 그 학생의 전체 체크 횟수(메모 포함)와 기록한 날 수입니다.

    7. 연락하기

    결석 학생

    • 지금 보고 있는 출석 체크의 결석 학생에게 전화·문자·메일을 보냅니다. ‘한 명씩 보내기’는 이름이 들어간 문구로 한 명씩 문자창을 엽니다.
    • 연락을 마친 학생은 ✓ 연락 완료. 출결은 결석 그대로 두고 연락 알림(아래 연락 버튼의 숫자)에서만 빠집니다.

    학생 골라 연락

    • 학급(여러 학급·모든 학급)을 고르고 학생을 체크한 뒤 문자·전화·이메일. 여러 명에게 메일을 보내면 숨은참조로 들어가 서로 주소가 보이지 않습니다.
    • 문구에 {이름}을 쓰면 한 명씩 보낼 때 학생 이름으로 바뀝니다.

    교사 · 교직원

    수업 교사에게 출석 현황을 문자로 보내거나, 교직원을 골라 연락합니다.

    앱은 휴대폰의 문자·전화·메일 앱을 열어 줄 뿐이며, 보내기는 직접 누릅니다. 문자는 휴대폰 번호로 나가므로 개인 번호를 감추려면 학교 업무폰이나 학교 문자 시스템을 쓰세요(‘번호 모두 복사’·‘문구 복사’ 활용).

    8. 시간표

    1. 시간표 → ＋ 새로: 학년도·학기를 정해 시간표를 만듭니다.
    2. 시간 설정: 1교시 시작, 수업 시간, 쉬는 시간, 점심시간을 넣으면 1~7교시가 자동 계산됩니다.
    3. 칸 편집: 칸을 눌러 과목·학급·강의실을 넣습니다. ‘다른 요일 같은 교시에도’로 한 번에 채울 수 있습니다.
    4. 편집을 마치고 칸을 누르면 그 날 그 교시의 출석 체크와 수업 메모장(진도·메모·과제·면담)이 열립니다.

    시간 바꾸기와 수업 변동

    • 왼쪽 교시를 누르면 그 교시의 시작·길이를, 위 요일을 누르면 그 날만(단축수업 등) 시간을 바꿉니다.
    • 칸 → ‘수업 변동’: 수업 변경·휴강·보강을 ‘이번 한 번만’ 또는 ‘기간 정하기’로. 요일 → ‘이 날 수업 변동’은 시험·행사 날 전체 휴강.
    • 시간표 아래 ‘수업 변동 (학사일정)’에서 모아 보고 취소합니다.

    9. 일정 · 알림 · 구글 캘린더

    • 시간표 → 일정 · 알림 → ＋ 일정 추가: 날짜·시간·분류·학급·메모·알림을 넣습니다.
    • ‘시간표에서 고르기’ 버튼: 1교시 이전, 쉬는 시간, 점심시간, 방과 후, 그날의 공강(초록)을 눌러 시간을 채웁니다.
    • 알림은 앱이 열려 있을 때 울립니다. 처음에 ‘알림 허용’을 눌러 주세요.
    • 앱을 닫아도 알림을 받으려면 일정의 구글 캘린더에 추가 또는 ‘앞으로의 일정 캘린더 파일로 보내기’를 쓰세요.

    10. 할 일

    • 일정과 수업 메모의 과제·면담이 지난 미완료 / 오늘 / 내일 / 이번 주 / 다음으로 나뉘어 보입니다.
    • 왼쪽 네모 = 완료, 내용 = 수정, 종 = 알림 시간. 기간·분류·중요한 것만으로 골라 봅니다.
    • ‘문자로 보내기’·‘이메일로 보내기’로 목록을 보내고, ‘알림 확인’에서 알림이 켜져 있는지 시험합니다.

    11. 수행평가 점수 보내기와 학생 자필 서명

    ① 전표 준비

    • 평가·통계 → 수행평가 서명 → 전표 양식 받기
      • 학급 명단으로 만들기: 학급을 고르고 평가 항목을 쉼표로 입력하면 학번·이름·이메일과 항목 칸이 들어간 엑셀 양식이 내려옵니다. 총점 칸에 합 수식을 넣을 수 있습니다.
      • 기본 양식: 예시가 든 양식
    • 전표 규칙: 1행은 제목(학번, 이름, 이메일, 항목…, 총점, 의견), 2행부터 학생 한 줄씩. 학교 전표(두 줄 제목, 병합 칸, 합계 수식)도 그대로 읽습니다.

    ② 평가 만들기

    • 전표 올리기: 파일을 고르면 미리보기가 나옵니다. 평가 이름, 학년도·학기, 학급, 서명 마감일, 학생에게 보여 줄 칸(✓ 켜짐 / 점선 꺼짐), 회신 받을 내 이메일을 확인하고 ‘평가 만들기’
    • ＋ 직접 만들기: 학급 명단으로 평가를 만들고 앱에서 점수를 입력합니다(총점 자동 계산).
    • 위쪽 학년도·학기·학급을 먼저 고르면 그 학급이 기본으로 잡힙니다.

    ③ 학생에게 보내기

    • Gmail로 보내기: 학생마다 자기 점수만 담긴 메일이 한 번에 나갑니다(처음에 ‘Gmail로 보내기’ 권한 허용).
    • 메일 앱으로 한 명씩: 누를 때마다 다음 학생 메일 창이 열립니다(권한 필요 없음).
    • 이메일이 없는 학생은 학생 줄의 문자·링크 복사.

    ④ 학생이 하는 일

    1. 메일·문자의 ‘점수 확인하고 서명하기’ 링크를 엽니다.
    2. 점수를 확인하고 ‘이의가 없습니다’ 체크 → 손가락으로 서명 → 서명 완료
    3. 선생님께 이메일 보내기 → 메일 앱에서 보내기까지 눌러야 전달됩니다.
    학생들에게 마지막 ‘메일 앱에서 보내기’ 단계를 꼭 안내하세요. 이 단계를 하지 않으면 서명이 선생님께 오지 않습니다.

    ⑤ 서명 받기와 관리

    • 선생님 메일로 온 ‘서명 링크’를 누르면 앱이 열리며 서명이 자동으로 들어갑니다. 여러 통은 메일 내용을 복사해 ‘서명 받기’ 칸에 붙여 넣으세요.
    • 평가 화면에서 전체 / 서명 안 함 / 서명함으로 골라 보고, 서명 안 한 학생에게 다시 보냅니다.
    • 보낸 뒤 점수를 고치면 ‘점수 바뀜’이 되어 다시 서명을 받아야 합니다.

    ⑥ 서명 넣은 전표 받기

    1. 엑셀 파일 또는 PDF로 인쇄를 누르면 출력 설정이 열립니다.
    2. 서명 여부를 표기할 학생을 고르고(모두 / 서명한 학생만 / 학생별), 서명하지 않은 학생에게 ‘개별 연락을 통해 성적을 확인함’ 문구를 넣을 수 있습니다(문구 수정 가능).
    3. 엑셀은 올린 전표의 서식 그대로 오른쪽 끝에 ‘학생 서명’(서명 그림)·‘서명 일시’ 칸이 붙습니다.

    ⑦ 보관함과 서명 현황 (5.4)

    • 평가가 끝나면 평가 마치고 보관. 위쪽 ‘보관함’에서 언제든 다시 열어 전표 보기로 확인하고 다시 내려받습니다.
    • 서명 현황 모아 보기: 고른 학년도·학기·학급의 평가별 서명한 학생 / 안 한 학생, 학생별 미서명 평가를 보고 엑셀로 받습니다.

    12. 출석 통계

    • 평가·통계 → 출석 통계: 기간(오늘·이번 주·이번 달·최근 30일·전체 또는 날짜 직접)과 학급을 고르면 학급별·일자별·학생별 통계가 나옵니다.
    • ‘이메일 보내기’는 통계가 채워진 메일 앱을 열고, ‘엑셀 파일로 보내기’는 파일을 첨부해 보냅니다.

    13. 백업 · 되돌리기 · 초기화

    • 설정 → 백업 · 초기화 → 백업 파일 저장: 모든 자료를 파일 하나로 저장합니다. 메일·드라이브에 보관하세요.
    • ‘백업 파일 불러오기’: 예전 버전 백업도 그대로 불러옵니다. ‘지금 데이터와 합치기’ 또는 ‘완전히 바꾸기’.
    • 불러오기·동기화 합치기를 잘못했으면 불러오기 전으로 되돌리기.
    • 새 주소로 옮길 때: 예전 주소에서 백업 파일 저장 → 새 주소에서 불러오기 (또는 두 곳 모두 같은 구글 계정으로 로그인)

    14. 화면 · 글자 크기 (기기 맞춤)

    앱은 쓰는 기기의 화면 크기를 보고 칸 크기와 배치를 자동으로 맞춥니다.

    기기자동 배치
    작은 휴대폰 (폭 380 미만)글자·여백을 조금 줄이고 시간표 월~금을 한 화면에 맞춤
    휴대폰 (세로)한 줄 배치, 아래 메뉴
    휴대폰 (가로로 눕힘)아래 메뉴를 낮게 해서 내용이 더 보이게
    태블릿가운데 넓게, 입력 창은 화면 가운데에
    컴퓨터 (넓은 창)메뉴가 왼쪽으로, 설정·출석·관찰 기록은 두 줄로

    직접 바꾸기

    1. 설정 → 화면 · 글자 크기 (기기 맞춤)을 엽니다. 맨 위에 지금 기기 종류와 화면 크기가 보입니다.
    2. 글자 크기: 자동 / 작게 / 보통 / 크게 / 아주 크게
    3. 화면 배치: 자동 / 한 줄(휴대폰처럼) / 넓게 두 줄(태블릿·컴퓨터)
    4. 메뉴 위치: 자동(넓으면 왼쪽) / 항상 아래
    5. 시간표: 한 화면에 맞추기 / 크게 보고 옆으로 밀기(칸이 작게 느껴질 때)
    6. 되돌리려면 모두 자동으로.
    이 설정은 기기마다 따로 저장됩니다. 휴대폰은 크게, 컴퓨터는 넓게처럼 기기에 맞게 정하세요. 구글 연동으로 다른 기기에 옮겨지지 않습니다.

    15. 자주 묻는 질문 · 문제 해결

    새 버전이 안 보여요

    앱을 완전히 닫았다가 다시 여세요(한두 번). 그래도 그대로면 몇 분 뒤 다시 해 보세요. 설정 맨 아래에서 버전을 확인합니다.

    ‘액세스 차단됨: … Google 인증 절차를 완료하지 않았습니다’

    그 계정이 아직 앱에 등록되지 않았습니다. 앱을 안내한 선생님(관리자)에게 계정 추가를 요청하세요.

    ‘오류 400: origin_mismatch’

    앱 주소의 구글 로그인 설정이 맞지 않습니다. 앱을 안내한 선생님(관리자)에게 알려 주세요.

    전표에서 점수 칸을 못 찾아요

    1행에 학번·이름·항목을 칸마다 하나씩, 2행부터 학생을 입력하세요. ‘(빈 칸)’으로 나오는 칸은 엑셀에서 파일을 열어 저장한 뒤 다시 올리세요.

    학생 서명이 안 들어와요

    학생이 ‘선생님께 이메일 보내기’ 뒤 메일 앱에서 ‘보내기’까지 눌렀는지 확인하세요. 받은 메일의 링크를 이 앱이 있는 기기(또는 같은 구글 계정으로 연동된 기기)에서 눌러야 합니다.

    문자가 자동으로 안 가요

    웹앱은 문자를 대신 보낼 수 없습니다. 내용이 채워진 문자창이 열리면 보내기를 직접 누르세요.

    글자가 너무 작거나 칸이 잘려 보여요

    설정 → 화면 · 글자 크기에서 글자 크기를 바꾸거나, 시간표를 ‘크게 보고 옆으로 밀기’로 바꾸세요.

    알림이 안 울려요

    알림은 앱이 열려 있을 때만 울립니다. 확실히 받으려면 구글 캘린더에 추가하세요. 할 일 → 알림 확인에서 시험할 수 있습니다.
