    1. 처음 시작하기

    처음 설정 안내 (5.16): 처음 앱을 열면 선생님 이름 → 학년도·학기 → 학급과 학생 명단 → 시간표를 한 화면씩 안내합니다. 명단은 ‘10101 김가람’처럼 붙여 넣거나 엑셀·CSV로 가져오고, ‘1 김가람’처럼 번호와 이름만 적으면 학급 이름(예: 1학년 3반)으로 학번(10301)을 만들어 줍니다. 다른 기기에서 쓰던 자료가 있으면 첫 화면 아래 ‘구글 계정에서’ 또는 ‘백업 파일에서’를 누르세요. 다시 보려면 설정 → 나와 계정 → 처음 설정 안내.

    앱 열기와 설치

    1. 안내받은 앱 주소(예: https://○○○.github.io/teachers-life/)를 엽니다. 아이폰은 Safari, 안드로이드는 Chrome으로 여세요.
    2. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.
      • 아이폰: 아래 공유 버튼(□↑) → 홈 화면에 추가
      • 안드로이드: 오른쪽 위 ⋮ → 앱 설치 또는 홈 화면에 추가
      • 앱 바로가기(5.37, 안드로이드): 설치한 앱 아이콘을 길게 누르면 오늘 · 할 일 추가 · 출석 체크 · 시간표가 나옵니다. 누르면 그 화면이 바로 열리고, 끌어다 홈 화면에 놓으면 아이콘처럼 쓸 수 있습니다. 업데이트 뒤 바로가기가 안 보이면 앱을 한 번 열고 닫거나, 지웠다가 다시 설치하세요(자료는 그대로). 아이폰은 바로가기를 지원하지 않습니다.
      • 컴퓨터 크롬: 주소창 오른쪽의 설치 아이콘(모니터 모양) → 설치
    3. 한 번 연 뒤에는 인터넷이 없어도 열립니다. (문자·전화·메일·동기화는 인터넷이 필요합니다)

    자료는 어디에 저장되나요?

    입력한 모든 자료는 쓰고 있는 휴대폰(또는 컴퓨터)의 브라우저 안에 저장됩니다. 앱을 만든 사람의 서버로는 아무것도 가지 않습니다. 구글 로그인을 켜면 같은 자료가 내 구글 드라이브의 앱 전용 숨김 폴더에도 저장되어 다른 기기와 맞춰집니다.

    브라우저의 ‘인터넷 사용 기록·사이트 데이터 삭제’를 하면 기기 안의 자료가 지워질 수 있습니다. 구글 연동을 켜 두거나 가끔 설정 → 백업 · 초기화 → 백업 파일 저장을 해 두세요.

    2. 휴대폰과 컴퓨터(크롬)에서 함께 쓰기

    같은 구글 계정으로 로그인하면 휴대폰 앱과 컴퓨터 크롬에서 같은 자료로 일합니다. 예를 들어 컴퓨터에서 엑셀로 명단을 올리면 휴대폰에도 들어오고, 휴대폰에서 한 출석 체크는 컴퓨터에서도 보입니다.

    처음 연결하기

    1. 컴퓨터 크롬에서 앱 주소를 열고 설정 → 구글 로그인 · 기기 연동 → Google 계정으로 로그인
    2. 구글 창에서 계정을 고르고, 권한 화면의 ‘Google Drive에서 자체 구성 데이터 확인·생성·삭제’에 체크 → 계속
    3. 휴대폰 앱에서도 같은 계정으로 똑같이 로그인합니다.
    4. 두 기기 모두 자료가 있으면 ‘처음 연동하기’ 창이 뜹니다. 보통은 두 자료 합치기를 고르세요.

    평소 쓰는 법

    • 내용을 바꾸면 몇 초 뒤 자동으로 올라가고, 다른 기기는 앱을 열거나 다시 볼 때 받아옵니다.
    • 화면 오른쪽 위 표시: 동기화됨 / 올릴 내용 있음 / 연동하려면 누르기
    • 구글 보안 정책상 로그인은 약 1시간 유지됩니다. ‘연동하려면 누르기’가 보이면 한 번 누르면 됩니다.
    • 바로 맞추려면 설정 → 지금 동기화
    • 두 기기에서 같은 내용을 동시에 고치면 지금 쓰는 기기 쪽을 우선하고 나머지는 합칩니다. 잘못되면 설정 → 백업 · 초기화 → 불러오기 전으로 되돌리기
    • 보고 있는 학급·화면, 할 일 보기 설정은 기기마다 따로입니다.

    계정 추가·전환

    설정 → ＋ 다른 구글 계정 추가 · 전환. 계정마다 자료가 따로 보관되어, 개인 계정과 학교 계정의 자료가 섞이지 않습니다. 원래 계정으로 돌아가려면 ‘○○(으)로 전환’을 누르세요.

    아이폰 홈 화면 앱에서 로그인 창이 닫히지 않으면 Safari에서 앱 주소로 열어 로그인하세요. 학교 구글 계정은 관리자가 막아 두었을 수 있으니 개인 계정을 권합니다.

    4. 학급 · 명단 · 연락처 (설정)

    5.38 최성보 표시: 설정 → 학생 명단 → 최성보 대상 고르기에서 최소성취수준 보장지도 대상 학생을 체크합니다(학생을 눌러 고치는 창에서도 가능). 출석 · 관찰 기록 · 학생 명단 · 학생 화면에 최성보가 붙고, 학번을 바꿔도 따라갑니다. 수업 중 화면을 학생에게 보여 줄 때는 설정 → 화면 · 글자 크기 → 최성보 표시 → 숨기기.

    학급 만들기·바꾸기

    1. 출석 화면 맨 위 학급 이름을 누르면 학급 목록이 열립니다.
    2. 새 학급 이름을 넣고 추가. 학급을 누르면 그 학급으로 바뀝니다. ‘수정’에서 이름 바꾸기·복사·삭제

    학생 추가·수정

    • 설정 → 학생 명단 · 연락처: 학번·이름·전화번호·이메일을 넣고 ‘학생 추가’
    • 목록의 학생을 누르면 고치기, 다른 학급으로 옮기기, 삭제. 학번을 바꾸면 출석·관찰 기록도 함께 옮겨집니다.
    • (5.44) 학생 줄을 왼쪽으로 밀면 수정 · 삭제가 바로 나옵니다. 지운 뒤 잠시 되돌리기가 나옵니다.
    • 많으면 ‘일괄 입력 · 파일 올리기’로 한 번에 넣으세요.

    수업 교사 · 교직원

    수업 교사는 학급마다, 교직원은 모든 학급이 같이 씁니다. 이름을 누르면 수정·삭제할 수 있고, 줄을 왼쪽으로 밀어도 수정 · 삭제가 나옵니다(5.44).

    교직원 입력 양식 (5.50): 이름 · 연락처 · 부서 · 업무 · 교과. 부서 · 교과는 이미 넣은 값이 목록으로 나옵니다. 일괄 입력 · 엑셀 양식도 같은 순서(이름, 연락처, 부서, 업무, 교과)이고, 첫 줄에 머리글이 있으면 열 순서가 달라도 알아서 맞춥니다. 예전 4칸 양식(이름, 연락처, 부서, 업무)도 그대로 읽습니다.

    회의 참석자 찾기: 회의 기록의 참석 교직원 고르기에서 이름 · 부서 · 교과 · 업무로 찾고, 부서 · 교과 단추로 거르고, 보이는 N명 모두 고르기로 한 번에 고릅니다. 명단에 없는 분은 이름을 직접 넣습니다.

    앱 배포 · 명단 공유

    • 앱 보내기 / QR 코드: 다른 선생님에게 앱 주소와 설치 안내만 보냅니다(명단 없음).
    • 명단 골라 공유: 학급·학생 명단·학생 연락처·수업 교사·교직원을 골라 링크·파일·QR로 보냅니다. 받는 분은 링크를 열면 로그인 없이 들어갑니다.
    • 학교 묶음 나눠 주기 (5.18): 설정 → 가져오기 · 공유 → 앱 배포 · 명단 공유 → 학교 묶음으로 고르기를 누르면 모든 학급 명단·수업 교사·교직원 연락처와 학교 공통 자료(수업 시간: 1교시 시작·수업·쉬는·점심시간·아침활동·조례 / 학사일정: 단축수업·시험·행사 등 하루 전체 수업 변동)가 한 번에 골라집니다. 학생 연락처는 꺼져 있으니 필요할 때만 켜세요. ‘관찰 기록 항목’도 골라 보낼 수 있습니다.
    • 받는 선생님은 링크를 열고 가르치는 학급만 고릅니다(학급이 많으면 처음에는 모두 꺼져 있고 ‘1학년’처럼 학년 단위로 고를 수 있음). 수업 시간은 받는 선생님의 같은 학기 시간표에 시간만 넣고(수업 칸은 그대로, 없으면 새로 만듦), 학사일정은 같은 일정이면 새로 고칩니다. 관찰 항목은 없는 것만 더합니다.
    • 처음 쓰는 선생님이 학교 묶음 링크를 열면 가져온 뒤 바로 ‘처음 설정 안내’(이름 → 학기 → 명단 → 시간표)로 이어집니다. 학사일정이 바뀌면 같은 방법으로 다시 보내면 됩니다.
    • 학급이 많으면 링크가 길어집니다. 문자로는 잘릴 수 있으니 메신저로 보내거나 ‘파일로 보내기’를 쓰세요(받는 분은 설정 → 백업 파일 불러오기, 또는 처음 화면의 ‘백업 파일에서’).
    연락처를 넣은 링크는 받은 사람 누구나 번호를 볼 수 있습니다. 같은 학교 선생님에게만 보내세요. 관찰 기록과 수행평가는 공유 링크에 들어가지 않습니다.

    4-0. 사용 교사 (출력물 표시)

    • 설정 → 사용 교사에 선생님 이름을 넣습니다. 이름을 넣지 않고 처음 파일을 내려받으면 이름을 묻는 창이 뜹니다.
    • 앱에서 내려받는 모든 엑셀·CSV 파일(명단·교사·교직원 입력 양식, 수행평가 전표 양식, 서명 넣은 전표, 서명 현황, 관찰 기록, 출석 통계·기록), PDF로 인쇄, 통계 메일의 문서 제목 아래 오른쪽에 ‘내려받은 일시 2026-10-18 15:40 · 출력한 사용자 교사 홍길동’이 자동으로 들어갑니다.
    • 학교 전표 양식에 서명을 넣어 받을 때는 표 제목 줄 바로 위에 한 줄을 넣어 표시합니다(병합 칸·합계 수식은 그대로 맞춰짐).
    • 앱에서 받은 양식을 채워 다시 올릴 때 맨 위 제목·내려받은 일시 줄은 그대로 두어도 됩니다.
    • 구글로 연동하면 이름이 다른 기기에도 같이 적용됩니다. 백업 파일·캘린더 파일·공유 파일은 문서가 아니라 표시하지 않습니다.

    4-1. 적용 기간 (학년도 · 학기)

    학급, 학생 명단·연락처, 수업 교사, 교직원 연락처, 평가는 학년도·학기별로 따로 관리됩니다. 지난 학기 자료는 지워지지 않고 남아 언제든 다시 볼 수 있습니다.

    1. 설정 → 적용 기간 (학년도 · 학기)에서 학년도와 학기를 고르면 그 기간의 학급·명단·연락처·평가가 출석·연락·평가·설정 화면에 보입니다.
    2. ‘등록된 기간’ 버튼을 누르면 그 기간으로 바로 바뀝니다. 출석 화면 맨 위 학급 이름 아래에도 지금 기간이 보입니다.
    3. 새 학기·학년도가 되면 ＋ 새 학기 · 학년도 시작하기:
      • 새 학년도·학기를 고르고, 복사해 올 기간과 학급을 고릅니다.
      • 학생 명단, 학생 연락처, 수업 교사, 교직원 연락처 중 복사할 것을 체크합니다. 출석·관찰 기록은 복사하지 않습니다.
      • 학년이 바뀌면 복사한 뒤 학급 이름·학번을 고치거나 명단을 새로 올리세요.

    설정할 학급 고르기

    설정 화면의 설정할 학급은 처음에 출석 화면에서 고른 학급입니다. 다른 학급을 고르면 출석 화면 학급을 바꾸지 않고도 그 학급의 이름·문자 문구·학생 명단·연락처·수업 교사를 고칠 수 있습니다. 노란 안내의 ‘출석 화면 학급으로’를 누르거나 다른 화면으로 가면 원래 학급으로 돌아갑니다.

    5. 출석 체크

    5.40 짧은 메모 보기 · 관찰 기록에서 쓰기: 출석 칸이나 관찰 목록의 작은 표시(주의 · 약속 · 특기 · 최성보)를 누르면 출석은 그대로 두고 그 학생 메모가 바로 열립니다. 출석 명단 위 메모 · 최성보 모아 보기로 반 전체 메모를 한 화면에서 봅니다. 관찰 기록에서 학생을 누르면 창 위쪽에서 최성보 대상 체크와 짧은 메모 쓰기 · 지킴 · 지우기를 바로 할 수 있습니다(바로 저장되고, 쓰던 관찰 메모는 그대로 남음).
    5.39 학생 짧은 메모: 출석 칸을 길게 누르면(또는 학생 화면 · 학생 고치기의 ‘짧은 메모’) 그 학생에게 주의(앞자리 배치, 복약 시간 등) · 약속(수업 중 학생과 한 약속) · 특기(잘하는 점) 메모를 40자 안으로 붙입니다. 출석 · 관찰 · 학생 명단 · 학생 화면에 작은 표시가 나오고, 목록 보기에서는 첫 메모 내용이 보입니다. 약속은 지키면 지킴을 눌러 닫고, 아직 지키지 않은 약속은 오늘 탭에 모입니다. 수업 중 화면을 보여 줄 때는 설정 → 화면 · 글자 크기 → 최성보 · 짧은 메모 표시 → 숨기기.
    1. 출석에서 날짜를 고르고 ＋ 출석 체크 시작(또는 ＋ 체크 추가). 지금 시간으로 체크가 생기며 하루 몇 번이든 됩니다.
    2. 학생 칸(줄)을 누르면 출석 ↔ 결석이 바뀝니다. ‘전원 출석’·‘전원 결석’도 있습니다.
    3. 5.26 명단이 먼저 나옵니다. 수업 시간·교과 이름·교시 고르기는 맨 위 한 줄(예: ‘4교시 물리 · 12:00’)을 누르면 펼쳐지고, 그 줄 오른쪽에 출석·결석 수가 보입니다.
    4. ▦ 격자 보기(기본): 학생 이름 칸이 한 줄에 4개씩 놓여 한 반이 한 화면에 들어옵니다. 결석은 빨간 칸. ☰ 목록 보기는 학생마다 이날 출석 흐름(점)과 연락 완료 표시까지 보여 줍니다. 고른 보기는 기기마다 기억합니다.
    5. 잠그기 · 휴강 · 결강 처리 · 이 출석 체크 삭제는 명단 아래에 있습니다.
    6. 체크마다 시간과 이름(예: 출발 전)을 바꿀 수 있습니다.
    7. 시간표의 수업 칸을 누르면 그 수업의 출석 체크가 바로 열립니다.

    잠금 · 잠금 해제 (5.4)

    • 체크를 마치면 잠그기를 누르세요. 잠긴 체크는 학생 줄을 눌러도 바뀌지 않고, 전원 출석·결석·삭제·시간 수정도 막힙니다. 위 시간 버튼에 🔒이 붙습니다.
    • 고쳐야 하면 잠금 해제 → 한 번 더 확인.

    휴강 · 결강 처리 (5.24.1)

    • 시간표에서 그 수업을 휴강·결강(수업 변동)으로 바꾸거나, 그날을 수업 없음(재량휴업·시험 등)으로 바꾸면, 그 수업의 출석 체크는 출석 통계·월별 출결표·결석 연락에서 자동으로 빠집니다. 출석 체크 화면에 ‘⛔ 결강 · 통계에서 빠집니다’가 보입니다.
    • 시간표와 연결되지 않은 출석 체크는 출석 체크 화면의 휴강 · 결강 처리를 눌러 휴강 / 결강 / 학교 행사 / 시험 중 고릅니다. 체크한 내용은 지워지지 않고, 휴강 처리 풀기로 되돌릴 수 있습니다.
    • 출석 통계 첫 칸에 뺀 횟수가 ‘휴강 ○회 뺌’으로 보입니다.

    6. 학생 관찰 기록

    5.47 미참여 · 미제출 유형: 평가 · 과제 → 학급을 눌러 체크 창에서 미참여(과제는 미제출) 학생 줄 아래의 유형 단추로 백지제출 · 자발적 미참여 · 장기 미인정 결석 중 하나를 고릅니다. 같은 단추를 다시 누르면 지워집니다.
    • 여러 학생은 체크 칸으로 고른 뒤 선택한 학생 유형에서 한꺼번에 정하거나 유형 지우기를 누릅니다(잠시 되돌리기 가능).
    • 목록 위에 유형별 인원(예: 장기 미인정 결석 2)이 나오고, 격자 칸에는 ‘백지 · 자발 · 장기결석’으로 보입니다. 명단 복사 · 전체 명단 복사 · 학생별 모아 보기에도 유형이 함께 나옵니다.
    • 출석 결석으로 자동으로 들어온 학생에게 유형을 정하면 선생님이 확인한 것으로 보고, 나중에 출석이 바뀌어도 그대로 둡니다. 학생을 빼거나 ‘늦게 냄’으로 바꾸면 유형은 지워집니다. 유형을 정해도 출석 체크는 바뀌지 않습니다.
    5.45 출석 → 평가 · 과제 자동 반영: 수행평가 · 형성평가는 평가일 · 평가한 수업 시간, 과제는 마감일 · 마감 수업 시간의 출석 체크에서 결석한 학생이 자동으로 미참여 · 미제출로 들어갑니다. 학급 체크 창에서 이런 학생에게는 빨간 결석 표시가 붙습니다.
    • 순서는 상관없습니다. 출석 체크를 먼저 하고 평가 · 과제를 나중에 만들어도, 만드는 즉시 그 날 출석에서 결석한 학생이 들어갑니다. 평가 · 과제를 먼저 만들어 두고 나중에 출석 체크를 해도 마찬가지입니다.
    • 출석을 고치면 따라 바뀝니다. 결석을 출석으로 고치면 자동으로 넣은 표시가 빠지고, 새로 결석으로 바꾸면 들어갑니다. 평가일 · 마감일을 바꾸면 바뀐 날의 출석에 맞춰 다시 맞춥니다.
    • 한 방향만 동기화합니다. 평가 · 과제 쪽에서 학생을 직접 고치면(예: 결석했던 학생이 나중에 평가를 보거나 과제를 내서 빼기 · 늦게 냄) 그 학생은 출석과 따로 관리되어 다시 자동으로 바뀌지 않고, 출석 체크 결과는 절대 바뀌지 않습니다.
    • 평가한 수업 시간(5.46): 평가 · 과제를 만들거나 고칠 때 학급마다 평가한 수업 시간(과제는 마감 수업 시간)을 고릅니다. 그 날 시간표의 수업(예: 1교시 물리학 (09:00))과 이미 한 출석 체크가 나오고, 수업이 하나뿐이면 저절로 정해집니다.
    • 같은 날 수업이 두 번 이상인 학급은 고른 수업(교시)의 출석 체크에서 결석한 학생만 들어갑니다. 시간을 고르지 않으면 어느 수업인지 확정할 수 없어 반영하지 않고, 체크 창에 ‘수업 시간을 정해 주세요’ 경고가 나옵니다. 수업 시간을 바꾸면 바뀐 수업의 출석에 맞춰 다시 맞춥니다.
    • 아직 아무도 출석으로 체크하지 않은 출석 체크(막 시작한 체크)는 반영하지 않습니다.
    • 평가 · 과제를 만들거나 고칠 때 출석 결석 자동 반영을 끄면 그 평가 · 과제는 반영하지 않습니다(끄면 자동으로 넣은 표시만 빠지고 직접 넣은 것은 남습니다).
    5.44 밀어서 수정 · 보관 · 삭제: 평가 · 과제와 글쓰기 목록의 줄을 왼쪽으로 밀면 수정 · 보관 · 삭제가 나옵니다. 학급 화면에서 여러 학급이 함께 쓰는 평가 · 과제는 빼기(이 학급에서만 빼기)입니다. 보관한 것은 목록 아래 📦 보관함에서 밀어 꺼내기로 되돌립니다. 자세히
    5.43.1 글쓰기 취소 · 삭제: 쓰는 창의 취소는 새 글이면 저장하지 않고 닫고, 이미 있던 글이면 연 뒤에 고친 내용과 새로 붙인 첨부를 되돌립니다(한 번 더 확인, ‘계속 쓰기’로 돌아갈 수 있음). 삭제는 두 번 눌러 지웁니다. 목록에서는 목록 편집 · 삭제를 눌러 골라서 한꺼번에 지우거나 하나씩 지우고, 취소로 빠져나옵니다. 줄을 왼쪽으로 밀어도 지울 수 있고, 지운 뒤 잠시 되돌리기가 나옵니다.
    5.43 글쓰기: 출석 → 글쓰기에서 학생 기록 · 회의 기록 · 일상 기록 · 자유 글을 고릅니다.
    · 학생 기록: 작성 일시(지금으로 채워짐), 학생 수를 넣으면 그만큼 학번 · 이름 · 전화번호(선택) 칸이 생깁니다. ‘우리 학생에서 고르기’로 내 학급 학생을 바로 채울 수 있고, 우리 반이 아닌 학생은 직접 적습니다. 장소(선택), 기록 내용.
    · 회의 기록: 일시, 회의명, 장소, 참석 인원(숫자) 또는 ‘교직원 고르기’(직접 이름 추가 가능), 회의 내용. · 일상 기록: 일시, 장소, 내용. · 자유 글: 제목과 내용.
    · 내용은 노션처럼 블록으로 씁니다. 줄 맨 앞에 #(제목) ##(소제목) -(목록) 1.(번호) [](할 일) >(인용) ---(구분선)을 쓰고 띄우면 바뀌고, /를 치면 블록 메뉴가 나옵니다. 위쪽 도구 막대로 블록 종류를 바꾸고 위 · 아래로 옮기거나 지웁니다. 쓰는 대로 저장됩니다.
    · 증빙: 사진 · 동영상 · 녹음 · 불러오기(PDF · 한글 등 파일). 첨부는 이 기기에만 저장되고, 글은 구글 연동 · 백업에 들어갑니다.
    · 목록의 전달 (5.51): 👩‍🏫 교직원에서 찾기(이름 · 부서 · 역할 · 교과로 찾기, 부서 · 교과 단추) · 🧑‍🎓 학생에서 찾기(학년 · 반 단추, ‘1학년 2반 김’처럼 학년 · 반 · 이름 · 학번으로 찾기)로 여러 명을 고르고, 명단에 없는 사람은 번호 · 메일을 직접 적습니다. 고른 사람은 칩으로 보이고 ×로 뺍니다. 문자는 번호 있는 사람 모두에게, 이메일은 주소 있는 사람에게 보냅니다. ‘공유하기’는 휴대폰 공유 창으로 첨부까지 함께 보냅니다(기기에 따라 다름). 언제 누구에게 보냈는지 남습니다. 학생 개인정보가 담긴 글은 꼭 필요한 사람에게만 전달하세요.
    5.42 미참여 · 미제출 학생 연락하기: 학급 체크 창의 미참여(미제출) 학생 연락하기(학생을 고르면 고른 학생만), 또는 출석 → 평가 · 과제 → 항목의 모두 연락하기(여러 학급 한꺼번에)를 누릅니다. 학생마다 문자 · 전화 · 메일 단추가 있고, 문자에는 그 학생 이름 · 학급 · 항목 · 날짜가 자동으로 들어갑니다. 번호가 있는 학생에게 한꺼번에 문자를 보낼 수도 있습니다(이때 이름 자리는 ‘해당’). 보낼 말은 고쳐 쓸 수 있고 기억됩니다({이름} {학급} {항목} {날짜}). 연락한 학생은 연락함으로 표시되어 체크 창에서도 보입니다.
    5.42 평가 · 과제 공통 관리와 연동: 출석 → 평가 · 과제 → ＋ 평가 · 과제 만들기에서 수행평가 · 형성평가 · 과제 중 고르고 이름 · 날짜를 넣은 뒤 실시할 학급을 고릅니다(‘모두’로 한 번에). 만든 항목을 누르면 학급별 미참여 · 미제출 인원이 보이고, 학급을 누르면 그 학급 학생을 체크하고 한 번에 넣고 뺄 수 있습니다. ‘고치기 · 학급 배분’에서 이름 · 날짜 · 종류 · 학급을 바꾸거나 삭제합니다(체크 기록이 있는 학급을 빼면 먼저 물어봄, 삭제는 되돌리기 가능).
    배분된 학급의 관찰 기록 → 평가 · 과제 점검에도 똑같이 나오고, 어느 쪽에서 체크해도 같은 기록입니다. 학급 관찰 기록에서 만들면 그 학급에만 배분되고 평가 · 과제(공통)에도 나옵니다. ‘○반에 배분된 것만 보기’로 지금 학급 것만 볼 수 있습니다. 학급 관찰 기록에서는 그 학급 것만 다루며, 여러 학급이 함께 쓰는 항목은 이름 · 학급을 바꿀 수 없고 이 학급에서 빼기만 됩니다(다른 학급 기록은 그대로).
    5.41 수행평가 · 과제 점검: 출석 → 관찰 기록 → 수행평가 · 과제 점검 → ＋ 수행평가 · 과제 만들기에서 종류(수행평가/과제)와 이름(예: 1차 실험 보고서 발표, 3단원 학습지), 날짜를 넣습니다. 열린 창에서 참여하지 않은(제출하지 않은) 학생 칸을 누르면 체크되고, 다시 누르면 풀립니다. 아래에는 체크된 학생과 안 된 학생이 나뉘어 나오고, 골라서 한 번에 넣기 · 빼기 · 늦게 냄을 할 수 있습니다(되돌리기 가능). 명단 복사, 보호자 문자도 됩니다. 학생별 모아 보기는 학생마다 안 낸 수행평가 · 과제를 한눈에 보여 줍니다.
    5.41 항목별 모아 보기: 빠른 체크로 기록하면 관찰 기록 화면에 ‘과제 미제출 3명 · 수행평가 미참여 2명’처럼 이 날 항목별 인원이 나옵니다. 누르면 그 항목에 체크된 학생과 안 된 학생이 나뉘어 보이고, 골라서 한 번에 넣고 뺄 수 있습니다. 이번 주 · 이 학급 전체로 바꾸면 날짜와 함께 모아 보고 뺄 수 있습니다(넣기는 ‘이 날’에서, 잠긴 날은 그대로). 빠른 체크 항목에 수행평가 미참여가 새로 들어갔습니다.
    1. 출석 → 관찰 기록으로 바꿉니다.
    2. 기록 날짜를 고릅니다. 고르지 않으면 오늘 날짜로 기록됩니다. 옆에 그날 기록 횟수와 누적 횟수가 보입니다.
    3. 빠른 체크: 위 항목(예: 질문함)을 누른 뒤 학생 이름을 누를 때마다 기록됩니다(×2, ×3…). 잘못 눌렀으면 아래 ‘되돌리기’. 항목을 다시 누르면 선택이 풀립니다.
    4. 학생 기록 창: 학생 줄의 ‘기록’(또는 항목 선택 없이 이름)을 누르면 태도·역량·특성 체크와 메모를 적습니다. 아래에 누적 집계와 지난 기록이 보입니다.
    5. ‘누적 기록 복사’로 세부능력 및 특기사항 작성에 붙여 넣고, ‘관찰 기록 엑셀로 받기’로 학생별 누적·날짜별 기록을 받습니다.
    6. ‘항목 편집’에서 우리 과목에 맞게 항목을 더하거나 지웁니다. ●을 누르면 좋음(초록)·보통·아쉬움(빨강)이 바뀝니다.

    학생 이름 아래의 누적 n회 · n일은 그 학생의 전체 체크 횟수(메모 포함)와 기록한 날 수입니다.

    글쓰기 꾸미기 · 표 · 그림 · 도화지 · 수식 (5.48)

    사진 · 동영상 · 녹음 (5.12)

    • 학생 줄의 기록을 눌러 학생 기록 창을 엽니다. 📷 사진 찍기·🎥 동영상 찍기는 휴대폰 카메라 앱이 열리고, 찍은 뒤 ‘사용’(확인)을 누르면 그 학생의 그 날 기록에 붙습니다.
    • 🎙 녹음은 앱 안에서 바로 녹음합니다(처음에 마이크 권한 허용, 최대 15분). 🖼 앨범·파일로 이미 찍어 둔 사진·동영상·녹음 파일을 붙일 수도 있습니다.
    • 붙인 파일을 누르면 보기·재생, 저장 · 보내기(휴대폰에 저장하거나 다른 앱으로 보내기), 삭제를 할 수 있습니다. 학생 줄에 📷·🎥·🎙 개수가 보이고, 관찰 기록 엑셀에도 개수가 들어갑니다.
    • 파일은 찍은 기기에만 저장됩니다. 구글 연동으로는 목록만 옮겨지고 파일은 옮겨지지 않으며, 백업 파일에도 들어가지 않습니다. 오래 보관할 파일은 ‘저장 · 보내기’로 따로 저장하세요. 사진은 저장 공간을 아끼려고 긴 변 1920px로 줄여 저장합니다.
    • 학생 사진·영상·음성은 개인정보입니다. 학교 지침에 따라 필요한 경우에만 찍고, 다 쓴 뒤에는 지워 주세요. 잠긴 날짜에는 붙이거나 지울 수 없습니다.

    관찰 기록 잠금 (5.11)

    • 기록 날짜 아래 잠그기를 누르면 그 날 관찰 기록이 바뀌지 않습니다(빠른 체크·저장·삭제가 막힘). 학생 기록 창은 볼 수만 있고, 누적 복사와 엑셀 받기는 그대로 됩니다.
    • 잠금 해제를 누르면 다시 고칠 수 있습니다. 잠금은 날짜별·학급별로 저장되고 구글 연동으로 다른 기기에도 같이 적용됩니다.

    한눈에 보기 · 세특 초안 (5.17)

    1. 출석 → 관찰 기록 → 학생 이름 → 맨 위 한눈에 보기 · 세특 초안.
    2. 출석(출석 횟수·결석한 날), 관찰 기록(자주 체크한 항목·메모), 학생 서명 상태가 한 화면에 모입니다.
    3. 관찰 기록으로 초안을 누르면 관찰 메모를 날짜 순으로 잇고, 자주 체크한 항목(긍정·중립만)을 한 문장씩 덧붙인 초안이 만들어집니다. 학생의 구체적인 활동과 변화가 드러나도록 고쳐 쓰세요.

    시간표 올리기 (컴시간 파일 · 캡처)

    1. 시간표 → 시간표 올리기 (컴시간 파일 · 캡처): 컴시간 알리미 등에서 주간 시간표 화면을 캡처한 사진이나 엑셀·CSV·HTML 시간표 파일을 고릅니다. 컴퓨터에서는 캡처 후 시간표 화면에서 Ctrl+V로 붙여 넣거나 파일을 화면에 끌어다 놓아도 됩니다.
    2. 앱이 요일·교시별 과목·학급·강의실을 읽어 표로 보여 줍니다. 사진과 비교해 틀린 칸을 고치세요. 한 칸에 과목 학급 강의실 순서로 씁니다 (예: 물리 1-1 과학실). ‘1-1’, ‘1학년 1반’은 등록된 학급과 자동으로 연결됩니다.
    3. 처음 등록하는 시간표면 고정(매주 반복되는 기본 시간표) 또는 임시(정한 기간에만 적용)를 고릅니다.
    4. 이미 시간표가 있으면 지금 시간표와 비교해 바뀐 수업 · 새 수업 · 빠진 수업을 보여 줍니다. 많이 바뀌었으면 고정, 사진 속 날짜의 주에 일부만 바뀌었으면 임시를 권합니다. 칸마다 고정 · 임시 · 두기를 고르고, 임시는 적용 기간(이번 주 · 다음 주 · 사진의 주)을 정한 뒤 ‘반영하기’를 누릅니다.
    사진 글자 읽기는 이 기기 안에서 처리되고 사진은 외부로 보내지 않습니다. 처음 한 번은 글자 읽기 파일(약 5MB)을 내려받으므로 인터넷이 필요합니다. 글자가 크고 선명하게 캡처할수록 정확합니다. 임시로 넣은 내용은 ‘수업 변동 (학사일정)’ 목록에서 지울 수 있고, 반영 전 상태는 설정 → 백업의 ‘불러오기 전으로 되돌리기’로 되돌릴 수 있습니다.

    학사일정 파일 올리기 (5.19)

    1. 시간표 → 일정 · 알림 → 학사일정 파일 올리기 (수업 변동 안에도 있습니다).
    2. 엑셀·CSV·PDF·사진(캡처)을 고르거나, 한글(hwp) 학사일정은 표를 복사해 아래 칸에 붙여 넣고 ‘붙여 넣은 글 읽기’. 연도가 없는 날짜는 3~12월은 고른 학년도, 1~2월은 다음 해로 봅니다.
    3. ‘월 | 일 | 요일 | 행사’ 표, ‘10.28.(수) ~ 10.30.(금) 지필평가’ 같은 목록, 날짜 칸에 행사가 적힌 달력형을 읽습니다. 이어지는 날의 같은 행사는 기간 하나로 묶습니다.
    4. 읽은 학사일정 확인: 행사 이름으로 넣는 방법을 골라 둡니다. 시험·휴업·방학·체육대회 등은 수업 없음(그날 시간표 수업이 휴강), 단축수업·방학식·졸업식 등은 단축수업(수업 시간을 줄인 시간표, 분은 위에서 정함), 그 밖은 일정만(‘오늘’과 일정 목록). 틀린 것은 이름과 방법을 고치세요. 지난 날짜는 기본으로 빠지고, 주말 휴일은 ‘넣지 않음’입니다.
    5. 넣기를 누르면 날짜에 맞는 학기의 시간표에 들어갑니다(그 학기 시간표가 없으면 지금 시간표의 시간으로 새로 만듭니다). 같은 일정은 다시 올려도 겹치지 않습니다.

    교사의 생활 학사일정 양식 (5.20)

    1. 학사일정 파일 올리기 창에서 양식 받기 (엑셀)를 누릅니다. 앱에 이미 넣은 학사일정이 있으면 그 내용이 채워진 양식이 내려옵니다.
    2. ‘학사일정’ 시트에 한 줄에 행사 하나씩 시작일 · 종료일 · 행사 · 구분 · 단축 수업 시간(분) · 비고를 채웁니다. 하루짜리는 종료일을 비워 둡니다. 날짜는 2026-10-28처럼 적습니다.
    3. 구분은 칸을 눌러 목록에서 고릅니다: 수업 없음 / 단축수업 / 일정만 / 넣지 않음. 비우면 행사 이름을 보고 앱이 고릅니다. 단축수업은 줄마다 한 교시 시간(분)을 적을 수 있습니다.
    4. 교시가 중요한 행사 (5.21): 교시 칸에 5,6 또는 5-6처럼 적습니다(비우면 하루 전체).
      • 요일 교체: 그날 정한 교시를 다른 요일 시간표대로 운영합니다. 예) 2026-11-06 · 금요일 2교시 월요일 수업으로 운영 · 요일 교체 · 교시 2 · 바꿔 운영할 요일 ‘월요일’. 선생님마다 자기 시간표의 월요일 2교시 수업으로 바뀝니다(그 교시에 수업이 없으면 휴강).
      • 교시 행사: 동아리·창체처럼 정한 교시에 하는 활동이 그 교시의 원래 수업 대신 시간표에 ‘행사’로 들어갑니다. 매주 반복에 ‘매주’를 고르면 시작일~종료일 사이 시작일과 같은 요일마다 들어갑니다. 학급을 고르면 그 칸을 눌러 그 학급 출석 체크를 할 수 있습니다.
      • 수업 없음에 교시를 적으면 그 교시만 휴강(예: 체육대회 오후 5-7), 일정만에 교시를 적으면 그 교시 시간으로 일정이 들어갑니다.
    5. 저장한 뒤 같은 창의 파일 고르기로 올리면 ‘교사의 생활 양식에서 읽었습니다’가 나오고, 양식의 구분 그대로 확인 화면에 들어옵니다. ‘예시’가 적힌 줄은 읽지 않습니다.
    6. 고쳐서 다시 올려도 같은 날 같은 행사는 겹치지 않습니다. 학교 학사일정 담당 선생님이 한 번 채워 나눠 주면 모두 같은 파일을 올리면 됩니다.
    스캔한 PDF나 흐린 사진은 잘못 읽을 수 있습니다. 확인 화면에서 꼭 살펴보세요. 넣은 학사일정은 학교 묶음으로 동료에게 나눠 줄 수 있습니다.

    1교시 이전 · 점심시간 · 방과 후 활동 (5.23)

    1. 시간표 맨 위 1교시 전(1교시 이전 시간을 만들었다면 그 줄), 점심, 맨 아래 방과 후 칸을 누릅니다.
    2. 매주 ○요일 고정 활동에서 조례 · 종례 · 정문지도 · 급식지도 · 상담 · 학생 활동 · 부서업무 · 동아리 · 보충수업 · 회의 중 고르거나 직접 적고 분류를 고른 뒤 고정 활동 저장. ‘월~금 모두’를 체크하면 다섯 요일에 한 번에 들어갑니다.
    3. 칸에 활동 이름(파란 글씨)과 그 날 그 시간의 일정 제목(노란 글씨)이 보입니다. 같은 창에서 이 날 이 시간에 일정 추가로 하루짜리 일정을 넣습니다.
    4. 일정 화면에서 1교시 이전·점심시간·방과 후 시간으로 일정을 넣어도 시간표 칸에 바로 보입니다. 일정 추가 창의 매주 같은 요일 고정 활동으로 시간표에 넣기를 고르면 일정 대신 시간표 고정 활동이 됩니다.
    5. 고정 활동은 ‘오늘’ 화면에도 나오고, 학사일정의 ‘수업 없음’인 날(휴업·방학 등)에는 숨겨집니다. 지우려면 칸을 눌러 고정 활동 지우기.

    9. 일정 · 알림 · 구글 캘린더

    5.39 알림 방식: 시간표 → 일정 · 알림 → 알림 방식에서 벨소리(맑은 차임 · 딩동댕 종 · 실로폰 · 부드러운 두 음 · 나무 종 · 소리 없음), 소리 크기, 진동(두 번 · 짧게 · 길게 · 심장 박동 · 잔잔한 물결 · 없음)을 고르고 미리 듣기 · 느끼기로 확인합니다. 수업 알림과 일정 알림에 함께 쓰이고, 앱이 열려 있을 때 울립니다. 진동은 안드로이드에서만 되고, 휴대폰 소리를 줄였거나 방해 금지 모드면 들리지 않을 수 있습니다.
    5.38 수업 시작 알림: 시간표 → 일정 · 알림 → 수업 시작 알림에서 5분 전(기본) · 3분 전 · 10분 전 · 끄기를 고릅니다. 앱이 열려 있으면 시작 전에 휴대폰 알림과 화면 위 알림이 울리고, ‘출석 열기’로 바로 출석 체크를 합니다. 휴강 · 주말 · 방학에는 울리지 않습니다. 앱을 닫아 두어도 받으려면 휴대폰 캘린더에 수업 알림 넣기로 이번 학기 수업을 매주 반복 일정(미리 알림 포함)으로 넣으세요(학기 종료일 필요, 휴강 · 단축 같은 변동은 반영되지 않음).
    • 시간표 → 일정 · 알림 → ＋ 일정 추가: 날짜·시간·분류·학급·메모·알림을 넣습니다.
    • ‘시간표에서 고르기’ 버튼: 1교시 이전, 쉬는 시간, 점심시간, 방과 후, 그날의 공강(초록)을 눌러 시간을 채웁니다.
    • 알림은 앱이 열려 있을 때 울립니다. 처음에 ‘알림 허용’을 눌러 주세요.
    • 앱을 닫아도 알림을 받으려면 일정의 구글 캘린더에 추가 또는 ‘앞으로의 일정 캘린더 파일로 보내기’를 쓰세요.

    10. 오늘 (할 일)

    5.44: 할 일 · 일정 줄을 왼쪽으로 밀면 완료 · 수정 · 삭제가 나옵니다(완료한 것은 되돌리기). 자세히
    5.30: 위쪽 숫자 칸(오늘 할 일 · 지난 미완료 · 남은 할 일)을 누르면 그 목록이 바로 열립니다. 네모를 누르면 완료, 줄을 누르면 고치기입니다.
    왼쪽으로 밀어 삭제: 할 일 · 일정 · 수업 변동 · 학생 명단 · 수업 교사 · 교직원 연락처 · 평가 목록의 줄을 손가락으로 왼쪽으로 밀면 빨간 삭제 단추가 나옵니다. 누르면 지워지고, 아래에 뜨는 되돌리기를 6초 안에 누르면 되살아납니다. 조금만 밀면 제자리로 돌아가고, 다른 곳을 누르면 닫힙니다. 원래 있던 수정 · 삭제 단추도 그대로 쓸 수 있습니다.
    5.17: 아래 메뉴의 ‘할 일’이 오늘로 바뀌었습니다. 맨 위 ‘오늘 수업’ 카드에서 하루를 시작하세요.
    5.26: 지난 할 일은 ‘지난 할 일 N개’로 접혀 있고 누르면 펼쳐집니다. 할 일이 많은 묶음은 8개까지만 먼저 보이고 ‘더 보기’로 나머지를 봅니다. 서명 마감은 가장 급한 2건과 요약(건수·미서명 수)만 보입니다. 아래 메뉴 ‘오늘’의 숫자는 오늘 할 일만 세고, 지난 할 일만 남아 있으면 작은 점으로 알려 줍니다.

    오늘 수업

    • 시간표의 오늘 수업이 시간 순서로 나오고, 수업마다 출석 6/8 · 결석 2 · 연락 전 2처럼 출석 체크 상태가 보입니다. 지금 수업과 다음 수업은 왼쪽에 색 줄로 표시됩니다.
    • 수업을 누르면 그 학급 출석 체크가 바로 열립니다. 끝난 수업인데 체크하지 않았으면 빨간색 출석 체크 안 함이 붙습니다. 휴강·변동도 함께 보입니다.
    • 연락할 결석 학생: 오늘 결석한 학생 중 아직 연락하지 않은 학생 수가 학급별로 나오고, 누르면 연락 화면으로 갑니다.
    • 서명 마감: 7일 안에 마감이거나 마감이 지난 학생 서명 중 아직 서명하지 않은 학생이 있는 것만 나옵니다.

    할 일 · 일정

    • 일정과 수업 메모의 과제·면담이 지난 미완료 / 오늘 / 내일 / 이번 주 / 다음으로 나뉘어 보입니다.
    • 왼쪽 네모 = 완료, 내용 = 수정, 종 = 알림 시간. 기간·분류·중요한 것만으로 골라 봅니다.
    • ‘문자로 보내기’·‘이메일로 보내기’로 목록을 보내고, ‘알림 확인’에서 알림이 켜져 있는지 시험합니다.

    11. 학생 자필 서명 받기 (수행평가 · 활동 확인 · 안내문 · 동의서)

    5.14부터 수행평가 점수 확인뿐 아니라 활동 참여 확인, 안내문·가정통신문 확인, 동의서·서약서, 직접 이름을 붙인 종류로도 서명을 받습니다. 만들 때 ‘무엇에 대한 서명인가요?’에서 종류를 고르면 학생 화면·메일 문구와 확인 문장(예: ‘위 내용을 읽고 이에 동의합니다’)이 알맞게 바뀝니다. 확인 문장은 고칠 수 있고, 점수 칸 없이 명단만으로도 만들 수 있습니다. 안내·동의 내용은 ‘학생에게 전할 말’에 쓰세요. 아래 설명의 ‘평가’는 이런 서명 받기 전체를 뜻합니다.

    ① 전표 준비

    • 평가·통계 → 수행평가 서명 → 전표 양식 받기
      • 학급 명단으로 만들기: 학급을 고르고 평가 항목을 쉼표로 입력하면 학번·이름·이메일과 항목 칸이 들어간 엑셀 양식이 내려옵니다. 총점 칸에 합 수식을 넣을 수 있습니다.
      • 기본 양식: 예시가 든 양식
    • 전표 규칙: 표의 제목 줄(학번, 이름, 이메일, 항목…, 총점, 의견) 아래로 학생 한 줄씩. 앱에서 받은 양식 맨 위의 문서 제목·‘내려받은 일시’ 줄은 그대로 두어도 됩니다. 학교 전표(두 줄 제목, 병합 칸, 합계 수식)도 그대로 읽습니다.

    ② 평가 만들기

    • 전표 올리기: 파일을 고르면 미리보기가 나옵니다. 평가 이름, 학년도·학기, 학급, 서명 마감일, 학생에게 보여 줄 칸(✓ 켜짐 / 점선 꺼짐), 회신 받을 내 이메일을 확인하고 ‘평가 만들기’
    • ＋ 직접 만들기: 학급 명단으로 평가를 만들고 앱에서 점수를 입력합니다(총점 자동 계산).
    • 위쪽 학년도·학기·학급을 먼저 고르면 그 학급이 기본으로 잡힙니다.

    ③ 학생에게 보내기

    • Gmail로 보내기: 학생마다 자기 점수만 담긴 메일이 한 번에 나갑니다(처음에 ‘Gmail로 보내기’ 권한 허용).
    • 메일 앱으로 한 명씩: 누를 때마다 다음 학생 메일 창이 열립니다(권한 필요 없음).
    • 이메일이 없는 학생은 학생 줄의 문자·링크 복사.

    ④ 학생이 하는 일

    1. 메일·문자의 ‘점수 확인하고 서명하기’ 링크를 엽니다.
    2. 점수를 확인하고 ‘이의가 없습니다’ 체크 → 손가락으로 서명 → 서명 완료
    3. 선생님께 이메일 보내기 → 메일 앱에서 보내기까지 눌러야 전달됩니다.
    학생들에게 마지막 ‘메일 앱에서 보내기’ 단계를 꼭 안내하세요. 이 단계를 하지 않으면 서명이 선생님께 오지 않습니다.

    ⑤ 서명 받기와 관리

    • 선생님 메일로 온 ‘서명 링크’를 누르면 앱이 열리며 서명이 자동으로 들어갑니다. 여러 통은 메일 내용을 복사해 ‘서명 받기’ 칸에 붙여 넣으세요.
    • 평가 화면에서 전체 / 서명 안 함 / 서명함으로 골라 보고, 서명 안 한 학생에게 다시 보냅니다.
    • 보낸 뒤 점수를 고치면 ‘점수 바뀜’이 되어 다시 서명을 받아야 합니다.

    ⑥ 서명 넣은 전표 받기

    출력 설정의 용지 방향은 기본이 ‘자동’입니다. 표 폭이 넓으면 가로, 좁으면 세로로 나가고 어느 쪽이든 한 페이지 너비에 맞춥니다. 필요하면 ‘세로’·‘가로’를 직접 고르세요(평가마다 기억). 제목이 길면 자동으로 줄바꿈됩니다.

    1. 엑셀 파일 또는 PDF로 인쇄를 누르면 출력 설정이 열립니다.
    2. 서명 여부를 표기할 학생을 고르고(모두 / 서명한 학생만 / 학생별), 서명하지 않은 학생에게 ‘개별 연락을 통해 성적을 확인함’ 문구를 넣을 수 있습니다(문구 수정 가능).
    3. 엑셀은 올린 전표의 서식 그대로 오른쪽 끝에 ‘학생 서명’(서명 그림)·‘서명 일시’ 칸이 붙습니다.

    ⑦ 보관함과 서명 현황 (5.4)

    • 평가가 끝나면 평가 마치고 보관(5.44부터 평가 목록의 줄을 왼쪽으로 밀어 보관, 보관함에서 밀어 꺼내기도 됩니다). 위쪽 ‘보관함’에서 언제든 다시 열어 전표 보기로 확인하고 다시 내려받습니다.
    • 서명 현황 모아 보기: 고른 학년도·학기·학급의 평가별 서명한 학생 / 안 한 학생, 학생별 미서명 평가를 보고 엑셀로 받습니다.

    ⑧ 평가 목록 삭제 (5.9)

    • 평가 목록 위 목록 편집 · 삭제를 누르면 평가마다 체크 칸과 삭제 버튼이 나옵니다.
    • 하나만 지울 때는 그 평가의 삭제를 두 번 누릅니다. 여러 개는 체크하거나 모두 선택한 뒤 선택한 평가 삭제를 두 번 누릅니다. 위쪽 학년도·학기·학급·진행 중/보관함 조건에 맞는 평가만 보입니다.
    • 학생 서명도 함께 지워집니다. 실수로 지웠다면 설정 → 백업 · 초기화 → 불러오기 전으로 되돌리기로 되돌릴 수 있습니다(다른 작업을 하기 전에).
    • 평가 화면 아래 이 평가 삭제로도 지울 수 있습니다.
    • (5.44) 평가 목록의 줄을 왼쪽으로 밀어 수정 · 보관 · 삭제를 바로 할 수 있습니다. 지운 뒤 잠시 되돌리기가 나옵니다.

    서명 요청 메일 모양 (5.24)

    • Gmail로 보내기: 반·제목, 점수 표, 큰 ✍️ 점수 확인하고 서명하기 버튼, 마감일이 카드 모양으로 갑니다. 긴 링크는 보이지 않고 버튼만 누르면 서명 화면이 열립니다.
    • 메일 앱으로 한 명씩: ‘메일 앱 본문’에서 표 · 서명 버튼 (붙여 넣기)를 고르면, 앱이 같은 모양의 본문을 복사해 두고 메일 앱을 엽니다. 받는 사람·제목은 채워져 있으니 본문을 길게 눌러 ‘붙여넣기’ 후 보내세요. 붙여 넣기가 되지 않는 메일 앱이면 글자만을 고르세요(점수를 줄로 정리하고 링크는 맨 아래 한 곳).
    • 서명 링크는 예전보다 약 절반 길이로 짧아졌습니다. 문자로 보낼 때도 짧게 갑니다.

    12. 출석 통계

    • 평가·통계 → 출석 통계: 기간(오늘·이번 주·이번 달·최근 30일·전체 또는 날짜 직접)과 학급을 고르면 학급별·일자별·학생별 통계가 나옵니다.
    • ‘이메일 보내기’는 통계가 채워진 메일 앱을 열고, ‘엑셀 파일로 보내기’는 파일을 첨부해 보냅니다.
    • 월별 출결표 (엑셀) (5.17): 달을 고르면 학생마다 한 줄, 출석 체크한 날마다 한 칸인 표를 학급별 시트로 만듭니다. 빈칸 = 출석, 결 = 그날 모든 체크에서 결석, 1/2 = 2번 중 1번 결석. 오른쪽에 결석 일수·결석 횟수, 맨 아래에 날짜별 결석 학생 수가 들어갑니다. 나이스 출결 입력이나 월말 확인에 쓰세요.

    학교 관리 (담당자용)

    5.31 · 1단계: 학교 전체 학급 · 학생 · 교직원 명단을 한곳에서 관리하는 학교 관리 담당자용 기능입니다. 보통 교무 · 정보 담당 선생님 한 분이 켭니다. 일반 수업 · 출석에는 필요 없습니다.
    • 설정 → 가져오기 · 공유 → 학교 관리 (관리자용)에서 개인정보 안내를 확인하고 켭니다. 켠 기기에서만 보입니다.
    • 명단 파일 올리기: 나이스에서 내려받은 학생 명부(학년 · 반 · 번호 · 성명), 학교에서 만든 명단, 교직원 연락망(성명 · 부서 · 직위 · 휴대전화) 엑셀이나 CSV를 그대로 고르면 됩니다. 위쪽에 제목 줄이 있어도, 시트가 여러 개여도 됩니다. 학번이 없으면 학년 · 반 · 번호로 만듭니다(1학년 3반 7번 → 10307).
    • 학생마다 바뀌지 않는 고유번호가 붙습니다. 반 이동이나 학번이 바뀌어도 같은 학생으로 알아봅니다.
    • 다시 올리기: 새 명부를 올리면 지금 원본과 비교해 전입 · 반 이동 · 학번 변경 · 이름 · 연락처 변경 · 전출 · 교직원 추가/변경을 항목별로 보여 줍니다. 체크를 빼서 원하는 것만, 펼쳐서 한 명씩 고를 수 있습니다. 새 명부에 없는 학생은 지우지 않고 전출로 표시합니다. 적용한 뒤에도 갱신 전으로 되돌리기가 됩니다.
    • 학급별 · 학생 찾기 · 교직원에서 보고 고치고 추가하며, 줄을 왼쪽으로 밀어 수정 · 삭제할 수 있습니다(삭제는 되돌리기 가능).
    • 개인정보: 원본은 이 기기에만 저장되고 구글 동기화에 들어가지 않습니다. 담당자는 학교의 정식 절차로 정하고, 개인정보 처리 지침을 먼저 확인하고, 원본 백업 저장 파일을 안전한 곳에 보관하세요.

    2단계 · 담당 배정과 한 번에 배포 (5.32)

    • 배정 탭에서 선생님마다 담임 학급과 과목별 수업 학급을 정합니다. 줄을 눌러 직접 고치거나, 수업 배정표 올리기로 엑셀을 올립니다. 목록형(성명 · 담임 · 과목 · 수업 학급)과 교사별 시간표(월 ~ 금 · 교시, 컴시간 등에서 내려받은 파일) 모두 읽고, 시간표 파일이면 선생님 시간표도 함께 보냅니다.
    • 학교 묶음 만들기: 파일 하나가 만들어집니다. 안에는 선생님마다 따로 잠긴 칸이 있어 개인 코드(8자)로 자기 칸만 열립니다. 담임은 학생 · 보호자 연락처까지, 교과 담당은 이름 · 학번 · 이메일만 받습니다(설정으로 바꿀 수 있음).
    • 개인 코드 보내기: 선생님별 코드를 문자 · 복사 · 안내표 엑셀로 한 번만 전합니다. 묶음을 새로 만들어도 코드는 그대로입니다.
    • 담당자 확인 코드(예: 23XB-AYX9)를 교무회의나 학교 공식 공지로 한 번 알려 주세요. 묶음에는 담당자 서명이 붙고, 선생님 앱은 처음 받을 때 이 코드를 대조해 기억합니다.

    배포 두 가지와 학사일정 · 교과 정보 (5.33)

    • 학교 묶음 배포 카드의 배포 방식에서 고릅니다. 둘 다 고르면 한 파일에 함께 들어가고, 선생님이 받을 때 방법을 고릅니다.
    • ① 배정 방식: 담당자가 배정 탭에서 정한 담임 · 수업 학급을 선생님마다 개인 코드로 받습니다.
    • ② 선택 방식: 선생님이 앱에서 먼저 내 학급(담임 · 과목별 수업 학급)을 정해 두면, 학교 묶음을 열 때 그 학급만 골라진 상태로 학교 공용 코드(8자) 하나로 받습니다. 학급마다 따로 잠겨 있어 고른 학급만 열립니다. 공용 코드는 여러 사람이 알게 되므로 기본은 이름 · 학번 · 이메일 · 교과 담당만 보내고, 연락처는 담당자가 따로 고를 때만 넣습니다.
    • 학사일정: 담당자 기기의 시간표 → 학사일정에 넣은 올해 일정이 함께 갑니다. 선생님 앱에서 일정 · 할 일 · 시간표 휴업 · 단축 · 교시 변동이 되고, 일정의 구글 캘린더 보내기도 그대로 됩니다.
    • 교과 수업 정보: 학급마다 담임과 과목별 담당 선생님이 수업 교사에 들어갑니다(연락처는 연락처를 보낼 때만).

    3단계 · 명단 갱신 배포 (5.34)

    • 담당자: 학교 묶음을 만들 때마다 그때 나눠 준 명단을 이 기기가 기억합니다. 새 명부를 올려 적용하면 배포 카드에 지난 배포 이후 바뀐 것(전입 · 반 이동 · 전출 · 학번 변경 · 이름 변경)이 보입니다. 묶음을 새로 만들어 올리기만 하면 됩니다(코드는 그대로).
    • 선생님: 새 묶음을 열면 이미 받은 학급은 학생 고유번호로 맞춰 보고 바뀐 것만 보여 줍니다. 들어옴 · 빠짐(전출 · 반 이동 → 어느 반) · 학번 · 이름 · 연락처 · 이메일을 하나씩 체크해서 적용합니다. 체크를 뺀 변경은 적용하지 않고 다음에 다시 보여 줍니다.
    • 빠진 학생은 명단에서만 빠지고 출석 · 관찰 · 세특 기록은 남습니다. 학번이 바뀌면 출석 · 관찰 · 세특 · 연락처가 새 학번으로 함께 옮겨집니다. 같은 학번의 학생이 이미 있으면 넣지 않고 담당자에게 확인하라고 알려 줍니다.
    • 적용한 뒤에도 되돌리기로 갱신 전으로 돌아갈 수 있고, 지난번보다 오래된 묶음을 열면 경고합니다.

    4단계 · 배포 기록과 담당자 인계 (5.35)

    • 배포 기록 탭: 묶음마다 만든 때, 배정한 선생님, 선택 방식 학급 수, 명단 변경, 학사일정이 남습니다. 기록 엑셀로 내보낼 수 있습니다.
    • 받음 확인: 선생님은 받은 뒤 설정 → 학교에서 받기 → 받았다고 알리기의 문장을 담당자에게 보냅니다. 담당자는 받은 문장들을 한꺼번에 붙여 넣고 받음 확인을 누릅니다. 문장 끝의 확인 4자는 묶음을 실제로 연 사람만 알 수 있어서, 다른 사람 문장을 이름만 바꾸면 ‘확인 안 됨’으로 나옵니다. 안 받은 선생님께 문자로 한 번에 알릴 수 있습니다.
    • 담당자 인계: 학교 관리 → 원본 관리 → 인계 파일 만들기. 원본 · 배정 · 개인 코드 · 학교 공용 코드 · 서명 열쇠 · 배포 기록이 인계 코드(12자)로 잠긴 파일 하나에 들어갑니다. 파일과 코드는 따로 전하세요.
    • 새 담당자: 설정 → 학교 관리 모드 켜기에서 인계 파일로 시작(또는 학교 관리 → 인계 파일 받기). 그대로 이어 쓰기를 고르면 확인 코드가 같아 선생님 앱에 아무 변화가 없습니다. 새 확인 코드로 바꾸기를 고르면 이전 담당자 열쇠로 넘김 서명을 붙여, 선생님 앱은 경고 대신 ‘담당자가 바뀌었습니다’ 안내만 보여 줍니다.
    • 새 담당자 기기에서 잘 보이는 것을 확인한 뒤, 이전 기기에서 이 기기의 학교 원본 지우기를 누르세요.

    5단계 · 학생 인계 카드 (5.36, 선택 사항)

    • 쓰지 않아도 됩니다. 담당자가 인계 카드 탭에서 ‘우리 학교는 인계 카드를 씁니다’를 켜고 묶음을 만든 학교에서만 선생님 앱에 ‘학생 인계 카드 만들기’가 보입니다(기본은 꺼짐). 선생님도 원하는 학급 · 학생에게만 만들고, ‘인계 메모를 쓴 학생만 보내기’를 고를 수 있습니다.
    • 선생님(학년말): 설정 → 가져오기 · 공유 → 학교에서 받기 → 학생 인계 카드 만들기에서 학교에서 받은 학급을 고릅니다. 학생마다 출석 요약과 관찰 경향이 자동으로 들어가고, 인계 메모에 다음 선생님께 필요한 사실(강점, 도움이 필요한 점, 해 온 지원)을 씁니다. 최근 관찰 메모 · 세특 초안은 고를 때만 들어갑니다. 쓰던 메모는 기기에 기억됩니다.
    • 인계 카드 파일 만들기로 만든 파일을 학교 관리 담당자에게 보냅니다. 이 파일은 담당자 기기에서만 열립니다.
    • 담당자: 학교 관리 → 인계 카드 탭 → 인계 카드 파일 받기(여러 개 한꺼번에). 카드는 학생 고유번호에 붙어 있어서, 새 학년도 명단을 올리고 배정한 뒤 학교 묶음을 만들면 새 담임에게 그 반 학생 카드만 들어갑니다. 교과 담당에게도 보내려면 ‘교과 담당에게도 넣기’를 켭니다. 선택 방식(학교 공용 코드)에는 넣지 않습니다.
    • 제출 현황(5.36.2): 인계 카드 탭에서 배정된 담임 선생님마다 보냄 · 아직 · 안 씀이 보입니다(‘교과 담당 선생님도 제출 대상에 넣기’를 켜면 교과 학급도). 아직 안 보낸 선생님께 문자로 한 번에 안내하고, 쓰지 않기로 한 선생님은 안 씀을 눌러 현황과 문자에서 뺍니다.
    • 새 담임: 학생 화면(관찰 → 학생 → 전체 보기)에 인계 카드가 보입니다. 참고용이며 다른 사람에게 옮기지 않습니다.
    • 민감한 내용(건강 · 가정 사정 등)은 학교 개인정보 지침에 따라 꼭 필요한 만큼만 쓰세요.

    선생님: 학교에서 받기

    • 설정 → 가져오기 · 공유 → 학교에서 받기에서 학교 묶음 파일을 엽니다(파일을 앱에 끌어다 놓아도 됨).
    • 처음에는 화면의 담당자 확인 코드가 학교에서 공지한 코드와 같은지 확인합니다. 내 이름을 고르고 개인 코드를 넣으면 내 칸이 열립니다.
    • 담임 학급(담임 표시) · 수업 학급 · 교직원 연락망 · 내 시간표(빈 칸만)가 들어갑니다. 이미 있는 학급은 새 학생만 더하고 출석 · 관찰 기록은 그대로입니다. 넣은 뒤 불러오기 전으로 되돌리기도 됩니다.
    • 받은 정보 관리(5.33): 다시 받기는 지난 묶음을 다시 엽니다. 되돌리기는 받기 바로 전 상태로 앱 전체를 돌립니다(그 뒤에 한 출석도 사라지므로 경고). 초기화는 받은 학급 · 교직원 연락처 · 학사일정 · 시간표 칸만 지우고, 출석 · 관찰 · 세특 · 평가 기록이 있는 학급은 기록과 함께 남긴 채 학교 연결만 풉니다.
    • 만든 뒤 내용이 바뀐 파일은 열지 않고, 지난번과 다른 담당자가 만든 묶음이면 경고합니다.

    13. 백업 · 되돌리기 · 초기화

    5.27 학년도 마감 · 보관: 설정 → 보관 · 화면 · 정보 → 학년도 마감 · 보관
    • 새 학년도가 시작되면 지난 학년도(예: 2025학년도)의 학급·명단·출석·관찰 기록·세특 초안·평가(원본 전표 포함)·시간표·수업 메모·일정·학사일정을 보관하기 한 번으로 보관함에 옮깁니다. 올해와 지금 보고 있는 기간은 보관하지 않습니다.
    • 휴대폰 기본 저장 공간(약 5MB)이 차지 않고 동기화도 가벼워집니다. 1년 치 자료(9학급 261명, 출석 709회) 기준으로 기본 저장 공간 사용이 거의 0이 되고 동기화 파일은 약 1/7로 줄었습니다.
    • 보관함은 이 기기와 구글 드라이브의 앱 전용 공간(구글 연동 중일 때)에 저장됩니다. 다른 기기에서도 보관함 목록이 보이고, 그 기기에서 되살리기를 누르면 드라이브에서 받아 옵니다.
    • 되살리기: 보관한 학년도가 그 학년도 그대로 돌아옵니다. 올해 같은 이름의 학급(예: 1학년 2반)과 섞이지 않습니다. 설정 → 적용 기간에서 그 학년도를 고르면 볼 수 있습니다.
    • 파일로 받기로 보관 파일을 한 부 더 저장해 두세요. 보관 파일 불러오기로 다시 넣을 수 있습니다. 백업 파일 저장에도 보관함이 함께 들어갑니다.
    • 관찰 기록의 사진·동영상·녹음은 이 기기에 그대로 남습니다.
    • 설정 → 백업 · 초기화 → 백업 파일 저장: 모든 자료를 파일 하나로 저장합니다. 메일·드라이브에 보관하세요.
    • ‘백업 파일 불러오기’: 예전 버전 백업도 그대로 불러옵니다. ‘지금 데이터와 합치기’ 또는 ‘완전히 바꾸기’.
    • 불러오기·동기화 합치기를 잘못했으면 불러오기 전으로 되돌리기.
    • 새 주소로 옮길 때: 예전 주소에서 백업 파일 저장 → 새 주소에서 불러오기 (또는 두 곳 모두 같은 구글 계정으로 로그인)

    5.39 하루 세 번 인사: 학기 중에는 아침(일과 시작), 오후(점심시간이 끝나면, 새로 추가), 저녁(마지막 수업이 끝나면) 하루 세 번 인사합니다. 날씨 지역을 고르면 오늘 날씨와 기온을 담고(설정 → 응원 메시지 · 음악 → 날씨 지역), 오늘 수업 · 할 일이 많은지 적은지에 맞춰 말이 달라집니다. 아침 · 오후에는 지금 기분을 고르면 그에 맞는 위로를 건네고, 그 기분을 기억했다가 오후 · 저녁 인사에 이어 말합니다. 기분은 이 기기에만 저장됩니다. 각 인사는 따로 끌 수 있습니다.
    • 아침 인사: 평일에 앱을 그날 처음 열면(오후 1시 전) ‘좋은 아침입니다, ○○ 선생님’과 그날의 응원 한마디, 오늘 수업·할 일 수가 나옵니다. ‘오늘 하루 시작하기’를 누르면 ‘오늘’ 화면으로 갑니다.
    • 저녁 인사: 마지막 수업이 끝난 뒤 앱을 열면 ‘오늘 하루 어떠셨나요? 오늘도 애쓰셨습니다.’와 위로의 말, 오늘 한 일이 나옵니다. 기분을 고르고 ‘오늘의 한 줄’을 남길 수 있습니다(이 기기에만 저장, 동기화·공유되지 않음).
    • 음악: 인사 창의 ▶를 누르면 나옵니다. 이 앱을 위해 새로 지은 피아노 곡 ‘아침 햇살’·‘저녁 노을’(각 1분 17초가량, 무음 모드에서도 미디어 소리로 나옴 · 안 들리면 미디어 음량 확인), 선생님의 음악 파일, 음악 링크(유튜브·음원 사이트) 중 설정 → 보관 · 화면 · 정보 → 응원 메시지 · 음악에서 고릅니다. 소리가 저절로 나지는 않습니다.
    • 같은 곳에서 아침·저녁 인사를 켜고 끄고, 저녁 인사 시각(마지막 수업 끝나면 · 16:30 · 17:30 · 19:00)과 주말 표시를 정하며, ‘지금 보기’로 미리 볼 수 있습니다. 하루에 한 번씩만 나옵니다.

    16. 자주 묻는 질문 · 문제 해결

    포스트잇 · 링크 모음 · 설문 · 서류 받기가 없어졌어요

    5.50부터 포스트잇과 링크는 글 안에 넣는 블록입니다(글에서 ‘/’ → 🗒 포스트잇 · 🔗 링크 카드). 5.53부터 수업자료 · 설문 · 화이트보드 · 서류 받기는 없어졌고, 예전에 만든 글은 목록에서 열어 보고 지울 수 있습니다(자세히).

    새 버전이 안 보여요

    5.44부터는 앱을 열 때, 컴퓨터에서 앱 창을 다시 볼 때, 인터넷이 다시 연결될 때, 켜 둔 동안 30분마다 새 버전을 확인합니다. 앱을 막 열었을 때 새 버전이 있으면 바로 바뀌고, 쓰는 중이면 ‘새 버전이 나왔습니다 · 지금 업데이트’ 안내가 나옵니다. 그래도 그대로면 설정 → 앱 정보 → 새 버전 확인 · 업데이트를 누르거나, 앱을 완전히 닫았다가 다시 여세요. 설정 맨 아래에서 버전을 확인합니다. 입력한 자료는 그대로입니다.

    컴퓨터에서 업데이트가 늦게 돼요

    5.43 이하는 컴퓨터에서 앱 창을 계속 켜 두면 새 버전 확인이 늦었고, 가끔 브라우저에 남은 옛 파일을 다시 받았습니다. 5.44에서 고쳤습니다. 5.44로 한 번 바뀐 뒤부터는 빨리 반영됩니다. 처음 한 번은 설정 → 앱 정보 → 새 버전 확인 · 업데이트를 눌러 주세요.

    결석한 학생이 평가 · 과제에 자동으로 미참여로 들어가요

    5.45부터 평가일(과제는 마감일)에 결석한 학생은 자동으로 미참여 · 미제출이 됩니다. 같은 날 수업이 두 번 이상이면 고친 창에서 고른 수업 시간(교시)의 출석만 반영합니다(5.46). 출석 체크와 평가 · 과제 만들기 중 어느 쪽을 먼저 해도 같습니다. 나중에 평가를 보거나 과제를 냈으면 평가 · 과제의 학급 체크 창에서 그 학생을 눌러 빼거나 ‘늦게 냄’으로 바꾸세요. 출석 체크 결과는 그대로 결석으로 남습니다. 자동 반영을 원하지 않으면 그 평가 · 과제의 이름 · 날짜 고치기에서 ‘출석 결석 자동 반영’을 끄세요. 자세히

    글쓰기에서 엔터를 쳐도 문단이 안 바뀌어요

    5.49에서 고쳤습니다. 한글을 조합하는 중이거나 휴대폰 자판에서도 엔터로 새 문단이 생깁니다. 그래도 안 되면 꾸미기 줄의 ↵(새 문단) 단추를 누르세요. 같은 문단에서 줄만 바꾸려면 Shift+엔터입니다.

    웹 페이지 링크가 너무 길어요

    그림이 많으면 링크가 길어져 문자 · 카톡에서 잘릴 수 있습니다. 링크 만들기 창에서 ‘그림 넣기’를 끄거나, 웹 페이지 파일(.html)로 저장해 학급 홈페이지 · 패들렛 · 구글 드라이브에 올려 게시하세요.

    손글씨가 글자로 잘 안 바뀌어요

    손글씨 → 글자는 기기 안에서 처리합니다. 크롬의 손글씨 인식이 없는 휴대폰 · 컴퓨터는 사진 글자 읽기 방식이라, 흘려 쓴 글씨는 틀리기 쉽습니다. 크고 또박또박, 줄을 맞춰 써 보세요. 결과 창에서 고친 뒤 넣을 수 있습니다. 많이 쓸 때는 휴대폰 자판의 필기 입력(삼성 키보드: 자판의 ✍ · Gboard: 설정 → 언어 → 필기)으로 글 칸에 바로 쓰는 것이 가장 정확합니다.

    수식이 네모나 글자로 보여요

    수식 프로그램을 처음 한 번 받아야 합니다. 인터넷에 연결된 상태에서 수식이 든 글을 한 번 열면 그 뒤에는 인터넷 없이도 보입니다.

    창이 길어서 닫기 단추를 찾기 어려워요

    창 위쪽 오른쪽 ×를 누르세요. 아래의 닫기 · 취소 줄도 창 아래에 붙어 있어 내리지 않아도 보입니다. 휴대폰 뒤로 가기, 컴퓨터 Esc 키로도 닫힙니다. 자세히

    줄을 밀어도 단추가 안 나와요

    손가락을 옆으로 충분히(줄 너비의 1/4쯤) 밀어 주세요. 위아래로 비스듬히 밀면 화면이 스크롤됩니다. 글쓰기의 ‘목록 편집 · 삭제’ 중에는 밀기가 꺼져 있습니다. 밀어서 처리할 수 있는 목록은 14. 목록 밀어서 처리에 있습니다.

    ‘액세스 차단됨: … Google 인증 절차를 완료하지 않았습니다’

    그 계정이 아직 앱에 등록되지 않았습니다. 앱을 안내한 선생님(관리자)에게 계정 추가를 요청하세요.

    ‘오류 400: origin_mismatch’

    앱 주소의 구글 로그인 설정이 맞지 않습니다. 앱을 안내한 선생님(관리자)에게 알려 주세요.

    출석으로 눌렀는데 결석으로 되돌아가요

    5.23.0 이하에서 구글 동기화 중에 생기던 문제로, 5.23.1에서 고쳤습니다. 휴대폰과 컴퓨터를 함께 쓰면 두 기기 모두 새 버전으로 업데이트하세요(설정 → 앱 정보 → 새 버전 확인 · 업데이트).

    구글 로그인이 풀리고 다시 로그인이 안 돼요

    구글 보안 정책상 로그인은 약 1시간마다 만료됩니다. 설정 → 구글 로그인 · 기기 연동의 다시 로그인(또는 화면 위 ‘다시 로그인’)을 누르세요. 창이 안 열리면 ① 주소창의 팝업 차단 표시를 눌러 허용 ② 학교 인터넷이면 휴대폰 데이터로 시도 ③ ‘로그인이 계속 안 될 때 → 로그인 상태 초기화’ 후 다시 로그인하세요. 자료는 지워지지 않습니다. ‘액세스 차단됨’이 나오면 앱을 안내한 선생님에게 계정 등록을 요청하세요.

    PDF로 인쇄한 뒤 원래 화면으로 돌아가기

    ‘PDF로 인쇄’는 앱 안에 인쇄 화면을 엽니다. 인쇄 창에서 프린터 대신 PDF로 저장(아이폰은 공유 → 파일에 저장)을 고른 뒤, 위쪽 ‹ 닫고 돌아가기나 휴대폰의 뒤로 버튼을 누르면 평가 화면으로 돌아옵니다.

    저장 공간이 부족하다고 나와요

    설정 → 백업 · 저장 공간에서 사용량을 확인하세요. 먼저 백업 파일 저장을 한 뒤, 평가·통계의 보관함에서 지난 평가를 목록 편집 · 삭제로 지우면 공간이 늘어납니다. 관찰 사진·녹음은 ‘저장 · 보내기’로 따로 보관한 뒤 지우세요. 아이폰은 홈 화면에 앱을 추가해 쓰면 자료가 자동으로 지워지지 않습니다.

    동기화가 ‘드라이브의 동기화 파일을 읽지 못했습니다’로 나와요

    5.13부터 동기화 파일을 압축해 올립니다. 휴대폰과 컴퓨터 모두 최신 버전으로 업데이트하세요(설정 → 앱 정보 → 새 버전 확인 · 업데이트).

    새 버전을 올렸는데 바뀌지 않아요

    GitHub에 올린 뒤 사이트에 반영되기까지 1~10분 걸립니다. 그 뒤 앱을 열면 바로 새 버전으로 바뀌고, 쓰던 중이면 ‘새 버전이 나왔습니다 · 지금 업데이트’ 안내가 나옵니다(5.44부터 컴퓨터에서는 창을 다시 볼 때 · 켜 둔 동안 30분마다 확인)(설정 → 앱 정보 → ‘새 버전 확인 · 업데이트’로 직접 확인 가능). 입력한 자료는 그대로입니다. 안내가 안 나오면 주소 뒤에 ?v=1처럼 숫자를 붙여 한 번 열어 보세요. 브라우저 기록 삭제에서 ‘쿠키 및 사이트 데이터’는 절대 지우지 마세요(앱 자료가 모두 지워짐).

    학교에서 앱이 열리지 않아요

    앱이 아니라 학교 인터넷이 주소(github.io)를 막는 경우가 대부분입니다. ① 휴대폰 와이파이를 끄고 데이터(LTE·5G)로 열어 보세요. 열리면 학교망 차단입니다. ② 집에서 한 번 열어 홈 화면에 추가해 두면, 학교에서 주소가 막혀도 저장된 앱으로 열립니다(구글 연동·메일 보내기 등 인터넷이 필요한 기능은 학교망에서 막힐 수 있음). ③ 업무용(내부망) PC는 인터넷이 막혀 있으므로 인터넷용 PC나 휴대폰을 쓰세요. ④ 계속 필요하면 학교 정보 담당 선생님께 앱 주소의 차단 해제(허용 목록 등록)를 요청하세요.

    전표에서 점수 칸을 못 찾아요

    제목 줄에 학번·이름·항목을 칸마다 하나씩, 그 아래 줄부터 학생을 입력하세요. ‘(빈 칸)’으로 나오는 칸은 엑셀에서 파일을 열어 저장한 뒤 다시 올리세요.

    학생 서명이 안 들어와요

    학생이 ‘선생님께 이메일 보내기’ 뒤 메일 앱에서 ‘보내기’까지 눌렀는지 확인하세요. 받은 메일의 링크를 이 앱이 있는 기기(또는 같은 구글 계정으로 연동된 기기)에서 눌러야 합니다.

    문자가 자동으로 안 가요

    웹앱은 문자를 대신 보낼 수 없습니다. 내용이 채워진 문자창이 열리면 보내기를 직접 누르세요.

    글자가 너무 작거나 칸이 잘려 보여요

    설정 → 화면 · 글자 크기에서 글자 크기를 바꾸거나, 시간표를 ‘크게 보고 옆으로 밀기’로 바꾸세요.

    알림이 안 울려요

    알림은 앱이 열려 있을 때만 울립니다. 확실히 받으려면 구글 캘린더에 추가하세요. 할 일 → 알림 확인에서 시험할 수 있습니다.

    17. 버전별 바뀐 점

    앱 안에서 도움말을 열면 최신 변경 내용이 자동으로 나옵니다.

    교사의 생활 · 만든 사람 물리공작소
