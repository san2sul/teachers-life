교사의 생활 자동 점검 (71가지 시험)
만든 사람 물리공작소

앱을 고친 뒤 저장소에 올리기 전에 이 점검을 한 번 돌리면, 출석·동기화·시간표·평가·보관·불러오기 같은
핵심 기능이 그대로 잘 되는지 몇 분 만에 확인할 수 있습니다. 앱이 동작하는 데에는 필요 없는 폴더입니다.

1. 놓는 곳
   - 이 tests 폴더를 index.html 이 있는 폴더(저장소 맨 위) 안에 그대로 둡니다.
     teachers-life/
       index.html
       tests/run_all.py   ← 여기
   - tests 폴더에는 파일이 3개뿐입니다(run_all.py · README.txt · bundle.zip). 시험 파일 60여 개는 bundle.zip 안에 묶여 있어
     깃허브 웹 업로드(한 번에 100개까지)에 걸리지 않습니다. bundle.zip 은 풀지 말고 그대로 두세요.
   - 저장소에 함께 올려도 됩니다. 시험 자료는 모두 가짜 이름·번호이고 비밀 정보는 없습니다.
     (깃허브 페이지에 공개되어도 괜찮지만, 원하지 않으면 컴퓨터에만 두고 쓰세요.)

2. 준비 (컴퓨터에서 처음 한 번)
   - 파이썬 3.10 이상
   - 명령 창에서:
       pip install playwright pillow openpyxl
       python -m playwright install chromium

3. 실행
   - 저장소 폴더에서:  python tests/run_all.py
   - 몇 개만:          python tests/run_all.py t105 t112
   - 끝에 "59/59 통과"가 나오면 됩니다. 실패하면 tests/_work/<시험 이름>.log 에 자세한 기록이 남습니다.

4. 알아 두기
   - 인터넷의 구글 서버에 접속하지 않습니다. 구글 로그인·드라이브·메일은 가짜(흉내)로 시험합니다.
   - t48 · t49 · t104 는 이 컴퓨터 안에서만 앱을 엽니다(localhost:8766).
   - 시험 중 만들어진 파일은 tests/_work 에 쌓이며, 지워도 됩니다.
   - 시험 자료는 2026학년도 2학기(10월) 기준으로 만들어져 있습니다. 해가 바뀌어 날짜 때문에 실패하는 시험이 생기면 시험 자료의 날짜를 고쳐야 합니다.
