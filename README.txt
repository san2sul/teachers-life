교사의 생활 설치 방법 (버전 5.59.0, 2026-10-26)
만든 사람 물리공작소

이 폴더는 휴대폰에서 앱처럼 쓰는 교사용 앱입니다. 자세한 사용법은 앱 안의 '? 도움말'(help.html)에 있습니다. 출석부, 수업 시간표, 수업 메모, 일정·알림, 연락을 한 곳에서 씁니다.
인터넷 주소(https)에 한 번 올려 두면, 선생님과 수업 교사 모두 그 주소로 설치해 씁니다.

1. 인터넷에 올리기 (처음 한 번)
   - 컴퓨터에서 https://app.netlify.com/drop 에 접속합니다.
   - 압축을 푼 'teachers-life' 폴더를 화면에 끌어다 놓습니다.
   - 잠시 뒤 https://○○○.netlify.app 같은 주소가 나옵니다. 이 주소가 앱 주소입니다.
   - 주소가 사라지지 않게 하려면 무료로 가입한 뒤 그 사이트를 내 계정에 등록(claim)하세요.
   - GitHub Pages 등 https 주소를 주는 다른 곳에 올려도 똑같이 동작합니다.

2. 선생님 휴대폰에 설치
   - 휴대폰 브라우저로 앱 주소를 엽니다. (아이폰은 Safari, 안드로이드는 Chrome)
   - 설정 화면 → '명단 가져오기'에 함께 받은 가져오기 코드를 붙여 넣고 '가져오기'를 누릅니다.
   - 아이폰: 공유 버튼 → 홈 화면에 추가 / 안드로이드: ⋮ 메뉴 → 홈 화면에 추가 (또는 앱 설치)

3. 다른 선생님에게 보내기 - 앱 배포 · 명단 공유 (버전 4.8)
   - 앱만 보내기: 설정 → '앱 배포 · 명단 공유' → '앱 보내기'(또는 '주소·설치 안내 복사', 'QR 코드')
     받은 선생님은 주소를 열고 홈 화면에 추가하면 됩니다. 명단·연락처는 들어가지 않습니다.
     QR 코드는 'QR 이미지 저장'으로 저장해 교무실 게시물이나 연수 자료에 넣을 수 있습니다.
   - 명단 골라 보내기: 보낼 학급(여러 학급, 모든 학급)을 누르고 학생 명단, 학생 연락처, 수업 교사, 교직원 명단, 교직원 연락처 중 보낼 것만 체크합니다.
     교직원은 '교직원 고르기'에서 부서별·사람별로 고를 수 있습니다. 아래에 보낼 내용이 요약되어 보입니다.
   - '공유 링크 만들기' → '보내기', '복사', 'QR 코드' 또는 '파일로 보내기'
   - 받은 선생님이 링크를 열면(파일은 설정 → '백업 파일 불러오기') 가져올 학급과 교직원을 골라 로그인 없이 바로 들어갑니다.
     같은 이름의 학급은 출석 기록은 두고 명단·연락처만 새로 고칩니다. 잘못 가져왔으면 '불러오기 전으로 되돌리기'를 누르세요.
   - 앱 주소가 https 인터넷 주소일 때만 다른 사람이 열 수 있습니다. 파일로 열어 쓰는 중이면 먼저 인터넷에 올리세요.

여러 학급 쓰기
   - 출석 화면 맨 위 학급 이름을 누르면 학급 목록이 열립니다. 여기서 학급을 바꾸거나 새 학급을 추가합니다.
   - 다른 담임 선생님이 보낸 공유 링크를 열면 '새 학급으로 추가'를 고를 수 있습니다. 같은 이름의 학급이 있으면 명단만 새로 고칠 수 있습니다.
   - 공유 링크는 고른 학급과 고른 내용만 담고, 백업 코드는 모든 학급과 기록을 담습니다.

시간표 (버전 3.0)
   - 아래 메뉴 '시간표'에서 '＋ 새로'를 눌러 학년도와 학기를 정하면 시간표가 만들어집니다.
   - '시간 설정'에서 1교시 시작 시간, 수업 시간, 쉬는 시간, 점심시간(분)을 넣으면 1~7교시 시간이 자동으로 계산됩니다. 점심시간은 4교시 다음입니다.
   - '칸 편집'을 누르고 칸을 눌러 과목, 학급, 강의실을 넣습니다. '다른 요일 같은 교시에도 똑같이 넣기'로 한 번에 채울 수 있습니다.
   - 편집을 마치고 칸을 누르면 그 날짜·교시의 학급 출석 체크가 바로 열립니다. 체크한 칸에는 출석 인원이 표시됩니다.
   - 다음 학기에는 '＋ 새로'에서 지금 시간표를 복사해 고치면 됩니다.
   - 수업 시간 조정: 시간표 왼쪽 교시(예: 3교시)를 누르면 그 교시의 시작 시간과 수업 길이를 바꿀 수 있고, 다음 교시는 자동으로 이어집니다.
   - 하루만 바꾸기: 시간표 위쪽 요일을 누르면 그날만 단축수업(40·35·30분) 등으로 시간을 바꿀 수 있습니다.

수업 변동 - 학사일정 반영 (버전 4.5)
   - 고정 시간표는 그대로 두고, 특정 날짜나 기간에만 수업을 바꿉니다.
   - 수업 칸을 눌러 '수업 변동'을 고르면 수업 변경(과목·학급·강의실), 휴강·결강을 '이번 한 번만' 또는 '기간 정하기'(예: 10/15~10/29 매주 목 6교시)로 넣을 수 있습니다.
   - 빈 칸을 누르면 '이번만 수업 넣기'로 보강·추가 수업을 넣습니다.
   - 요일을 눌러 '이 날 수업 변동'을 고르면 시험·체육대회·재량휴업일처럼 하루(또는 며칠) 전체 수업을 휴강으로 바꿉니다.
   - 사유(중간고사, 체육대회, 수업 교체 등)를 함께 적고, 바뀐 칸에는 '변경'·'보강'·'휴강'이 표시됩니다.
   - 시간표 아래 '수업 변동 (학사일정)'에서 모든 변동을 보고 고치거나 '변동 취소'로 원래 시간표로 되돌립니다.
   - 변동된 수업 칸에서 출석 체크를 하면 바뀐 과목·학급으로 기록됩니다.

깃허브 웹사이트로 올릴 때 (중요)
   - 깃허브의 'Add file → Upload files'는 한 번에 100개까지만 받습니다. 이 앱 전체는 100개가 안 되어 한 번에 올라갑니다.
   - 점검 묶음(tests 폴더)은 파일 3개(run_all.py · README.txt · bundle.zip)입니다. bundle.zip 은 풀지 말고 그대로 올리세요.
   - 다음 업데이트부터는 바뀐 파일만 올려도 됩니다(보통 index.html · sw.js · manifest.webmanifest · help.html · 버전기록·설치방법).
   - 5.50 새 파일: form.html(학생 서류 작성 페이지) · tlform.js(서류 양식). 업데이트 묶음에 들어 있으니 다른 파일과 같이 올리세요.
   - 5.52 새 파일: tlsheet.js · forms/galmae/ 폴더(그림 5개). forms 폴더 안에 galmae 폴더가 있는 구조 그대로 올리세요.

새 폴더 fonts (버전 5.29)
   - fonts 폴더(Pretendard 글꼴)를 함께 올려 주세요. 설정에서 Pretendard를 고른 기기만 내려받습니다.
   - 자동 점검 묶음(teachers-life-tests 압축 파일)은 앱에 꼭 필요하지는 않습니다. 저장소에 tests 폴더로 넣어 두면 업데이트 전에 python tests/run_all.py 로 41가지를 한 번에 점검합니다(tests 폴더 안의 README.txt 참고).

학년도 마감 · 보관 (버전 5.27)
   - 새 학년도가 시작되면 설정 → 보관 · 화면 · 정보 → '학년도 마감 · 보관'에서 지난 학년도를 '보관하기' 하세요. 휴대폰 저장 공간이 넉넉해지고 동기화가 빨라집니다.
   - 보관한 자료는 같은 곳의 '되살리기'로 언제든 다시 꺼낼 수 있습니다. '파일로 받기'로 한 부 더 저장해 두면 휴대폰을 바꿔도 안심입니다.

출석 화면 · 오늘 탭 정리 (버전 5.26)
   - 출석 화면은 학생 명단이 먼저 나옵니다. 수업 시간·이름은 맨 위 한 줄을 누르면 펼쳐집니다.
   - 명단은 ▦ 격자(이름 칸)로 바뀌었습니다. 예전 모양이 편하면 ☰를 누르세요.
   - 잠그기와 '이 출석 체크 삭제'는 명단 아래에 있습니다.

앱 음악 파일 (버전 5.25.1)
   - 새로 생긴 sounds 폴더(morning.mp3, evening.mp3)를 index.html · sw.js와 함께 꼭 올려 주세요. 빠지면 앱 음악이 나오지 않습니다.
   - 소리가 작거나 안 들리면 휴대폰의 '미디어 음량'을 올려 주세요.

응원 한마디 · 하루를 여는 음악 · 닫는 음악 (버전 5.25)
   - 평일 아침 앱을 처음 열면 응원 메시지가, 마지막 수업이 끝난 뒤 열면 '오늘 하루 어떠셨나요? 오늘도 애쓰셨습니다.'가 하루에 한 번씩 나옵니다.
   - 인사 창의 ▶를 누르면 음악이 나옵니다. 앱 음악('아침 햇살' · '저녁 노을'), 내 음악 파일, 음악 링크 중 설정 → 응원 메시지 · 음악에서 고릅니다.
   - 끄려면 인사 창 아래 '그만 보기' 또는 설정에서 끄기.

학생 서명 요청 메일 (버전 5.24)
   - Gmail로 보내면 점수 표와 '점수 확인하고 서명하기' 버튼이 든 메일이 가고 긴 링크는 보이지 않습니다.
   - 메일 앱으로 보낼 때는 학생 서명 화면의 '메일 앱 본문'에서 '표 · 서명 버튼 (붙여 넣기)'를 고르세요. 메일 앱이 열리면 본문을 길게 눌러 '붙여넣기' 하면 같은 디자인이 들어갑니다. 붙여 넣기가 안 되는 메일 앱이면 '글자만'을 고르세요.
   - sign.html도 바뀌었으니 함께 올려 주세요.

1교시 이전 · 점심시간 · 방과 후 활동 (버전 5.23)
   - 시간표의 '1교시 전', '점심', '방과 후' 칸을 누르면 '매주 ○요일 고정 활동'에서 조례·정문지도·상담·부서업무 등을 고르거나 직접 적어 저장합니다. '월~금 모두'를 고르면 한 번에 들어갑니다.
   - 같은 창에서 그 날 그 시간의 일정도 보고 추가할 수 있습니다. 일정 화면에서 그 시간대로 일정을 넣어도 시간표 칸에 제목이 보입니다.
   - 일정 추가 창에서 '매주 같은 요일 고정 활동으로 시간표에 넣기'를 고르면 일정 대신 시간표 고정 활동으로 들어갑니다.

구글 앱 확인(인증) 준비 (버전 5.22)
   - 새 파일 home.html(앱 소개), terms.html(이용약관)을 함께 올리세요. 구글 클라우드 콘솔의 앱 홈페이지 · 개인정보처리방침 · 서비스 약관 주소로 씁니다.
   - config.js에 gmail: false 가 생겼습니다. 구글이 Gmail 권한(gmail.send) 확인을 마치면 true로 바꿔 올리세요. 그 전에는 'Gmail로 한꺼번에 보내기' 버튼이 숨겨지고, 설정 → 구글 로그인에서 기기별로만 켤 수 있습니다.
   - config.js를 직접 고쳐 쓰고 계셨다면, 새 config.js의 gmail 줄만 옮겨 넣어도 됩니다.

학사일정 양식 - 교시 행사 · 요일 교체 (버전 5.21)
   - 양식(학사일정 파일 올리기 → 양식 받기)에 교시, 바꿔 운영할 요일, 매주 반복, 학급(선택) 칸이 생겼습니다.
   - 요일 교체: 예) 2026-11-06 | 금요일 2교시 월요일 수업으로 운영 | 요일 교체 | 교시 2 | 월요일. 교시를 비우면 하루 전체를 그 요일 시간표로 운영합니다.
   - 교시 행사: 예) 2026-09-04 ~ 2026-12-18 | 동아리 활동 | 교시 행사 | 교시 5,6 | 매주. 그 교시의 원래 수업 대신 행사가 시간표에 들어갑니다.
   - 수업 없음 + 교시: 그 교시만 휴강 (예: 체육대회 오후 5-7). 일정만 + 교시: 그 교시 시간으로 일정이 들어갑니다.

학사일정 양식 (버전 5.20)
   - 시간표 → 일정 · 알림 → '학사일정 파일 올리기' → '양식 받기 (엑셀)'. 한 줄에 행사 하나씩 시작일 · 종료일 · 행사 · 구분 · 단축 수업 시간(분)을 채워 같은 창에서 올립니다.
   - 구분은 목록에서 고릅니다: 수업 없음(그날 휴강) / 단축수업(수업 시간 줄임) / 일정만('오늘'·일정 목록) / 넣지 않음. 비우면 행사 이름을 보고 앱이 고릅니다.
   - 앱에 학사일정을 이미 넣었다면 그 내용이 채워진 양식이 내려옵니다. 고쳐서 다시 올리면 됩니다. 이 파일을 동료에게 보내 함께 써도 됩니다.

학사일정 파일 올리기 (버전 5.19)
   - 시간표 → 일정 · 알림 → '학사일정 파일 올리기'(수업 변동 안에도 있음). 엑셀·CSV·PDF·사진(캡처)을 올리거나, 한글(hwp) 파일은 표를 복사해 붙여 넣습니다(또는 한글에서 PDF로 저장).
   - 읽은 일정 확인 화면에서 행사마다 '수업 없음 / 단축수업 / 일정만 / 넣지 않음'을 확인하고 '넣기'. 수업 없음은 그날 시간표가 휴강으로, 단축수업은 줄어든 수업 시간으로 바뀝니다.
   - 같은 파일을 다시 올려도 겹치지 않습니다. 학교 묶음으로 동료에게 학사일정을 나눠 줄 수도 있습니다.
   - GitHub에 올릴 때 vendor/pdf 폴더(PDF 읽기)도 함께 올려 주세요.

학교 묶음 나눠 주기 (버전 5.18)
   - 보내는 선생님(담임·부장 등): 설정 → 가져오기 · 공유 → 앱 배포 · 명단 공유 → '학교 묶음으로 고르기' → '공유 링크 만들기'(또는 '파일로 보내기'). 모든 학급 명단, 수업 교사, 교직원 연락처, 수업 시간, 학사일정이 함께 들어갑니다. 학생 연락처는 꺼져 있습니다.
   - 받는 선생님: 링크를 열고 가르치는 학급만 골라 '가져오기'. 수업 시간과 학사일정은 내 시간표에 들어가고(수업 칸은 그대로), 처음 쓰는 선생님은 바로 '처음 설정 안내'로 이어집니다.
   - 학사일정을 바꾸면 같은 방법으로 다시 보내면 됩니다. 같은 일정은 새로 고치고 겹치지 않습니다.
   - 학급이 많으면 링크가 길어 문자로는 잘릴 수 있습니다. 메신저나 '파일로 보내기'를 쓰세요.

오늘 · 세특 초안 · 월별 출결표 (버전 5.17)
   - 아래 메뉴 '할 일'이 '오늘'로 바뀌었습니다. 맨 위 '오늘 수업'에서 수업마다 출석 체크 상태를 보고, 누르면 바로 출석 체크가 열립니다. 연락할 결석 학생과 7일 안 서명 마감도 함께 나옵니다.
   - 출석 → 관찰 기록 → 학생 이름 → '한눈에 보기 · 세특 초안'에서 출결·관찰·서명을 모아 보고, '관찰 기록으로 초안'으로 세특 초안을 만들어 나이스 byte를 확인하며 고쳐 씁니다. 학급 전체 초안은 관찰 기록 화면 아래 '세특 초안 → 엑셀로 받기'.
   - 평가·통계 → 출석 통계 → '월별 출결표 (엑셀)'에서 달을 고르면 학생 × 날짜 출결표를 받습니다.

처음 설정 안내 (버전 5.16)
   - 처음 앱을 열면 '선생님 이름 → 학년도 · 학기 → 학급과 학생 명단 → 시간표'를 한 화면씩 안내합니다. 3분이면 끝납니다.
   - 명단은 '10101 김가람'처럼 학번과 이름을 붙여 넣거나 엑셀·CSV 파일로 가져옵니다. '1 김가람'처럼 번호와 이름만 적으면 학급 이름(예: 1학년 3반)으로 학번(10301)을 만들어 줍니다.
   - 담임 학급과 수업 들어가는 학급을 모두 넣어 두면, 시간표를 올릴 때 '1-3' 같은 칸이 학급과 자동으로 연결됩니다.
   - 다른 기기에서 쓰던 자료가 있으면 첫 화면 아래 '구글 계정에서' 또는 '백업 파일에서'를 누르세요.
   - 동료에게 앱을 알려 줄 때는 주소만 보내면 됩니다. 다시 보려면 설정 → 나와 계정 → '처음 설정 안내'.

화면 디자인 정리 (버전 5.15)
   - 기능은 그대로이고 모양만 바뀌었습니다. 카드 테두리 대신 여백으로 구역을 나누고, 진한 남색은 주요 버튼과 고른 항목에만 씁니다.
   - 긴 설명 글은 각 카드 아래 'ⓘ 사용 방법'을 누르면 보입니다. 늘 펼쳐 두려면 설정 → 화면 · 글자 크기 → '사용 방법 설명: 항상 펼쳐 두기'.
   - 설정은 네 묶음(나와 계정 / 학기 · 학급 · 명단 / 가져오기 · 공유 / 보관 · 화면 · 정보)의 목록입니다. 항목을 누르면 펼쳐집니다. 구글 로그인은 '나와 계정 → 구글 로그인 · 기기 연동'에 있습니다.

시간표 올리기 - 컴시간 파일 · 캡처 (버전 5.8)
   - 시간표 화면 → '시간표 올리기 (컴시간 파일 · 캡처)'를 누르고, 컴시간 알리미 등에서 주간 시간표 화면을 캡처한 사진이나 엑셀·CSV·HTML 시간표 파일을 고릅니다. 컴퓨터에서는 캡처한 뒤 시간표 화면에서 Ctrl+V로 붙여 넣거나 파일을 끌어다 놓아도 됩니다.
   - 사진은 휴대폰(브라우저) 안에서 글자를 읽으며 외부로 보내지 않습니다. 처음 한 번은 글자 읽기 파일(약 5MB)을 내려받으므로 인터넷이 필요합니다.
   - 읽은 결과가 표로 나오면 사진과 비교해 틀린 칸을 고칩니다. 한 칸에 '과목 학급 강의실' 순서(예: 물리 1-1 과학실)로 씁니다.
   - 처음 등록: '고정 시간표'(매주 반복) 또는 '임시 시간표'(정한 기간만)를 고릅니다.
   - 이미 시간표가 있을 때: 지금 시간표와 비교해 바뀐 수업·새 수업·빠진 수업을 보여 주고, 많이 바뀌었으면 고정, 특정 주의 일부만 바뀌었으면 임시를 권합니다. 칸마다 고정·임시·그대로 두기를 고르고, 임시는 적용 기간을 정합니다. 임시로 넣은 것은 '수업 변동 (학사일정)' 목록에서 볼 수 있습니다.
   - 반영 전 상태는 설정 → 백업 · 초기화의 '불러오기 전으로 되돌리기'로 되돌릴 수 있습니다.
   - 컴시간 알리미 사이트에서 자동으로 가져오지는 않습니다(사이트가 자동 수집을 허용하지 않음). 화면 캡처나 파일로 올려 주세요.

사용 교사 · 출력물 표시 (버전 5.10)
   - 설정 → '사용 교사'에 선생님 이름을 넣으면, 앱에서 내려받는 모든 엑셀·CSV 파일, PDF 인쇄, 통계 메일의 문서 제목 아래 오른쪽에 '내려받은 일시 2026-10-18 15:40 · 출력한 사용자 교사 홍길동'이 자동으로 들어갑니다.
   - 이름을 넣지 않은 채 처음 내려받으면 이름을 묻습니다. 구글로 연동하면 다른 기기에도 같이 적용됩니다.
   - 앱에서 받은 양식을 채워 다시 올릴 때 맨 위 제목·내려받은 일시 줄은 그대로 두어도 됩니다.

수행평가 목록 삭제 (버전 5.9)
   - 평가·통계 → 수행평가 서명 → 평가 목록 위 '목록 편집 · 삭제'를 누르면 평가마다 삭제 버튼과 체크 칸이 나옵니다. 여러 개를 골라 '선택한 평가 삭제'를 두 번 누르면 한 번에 지워집니다.
   - 학생 서명도 함께 지워지며, 실수로 지웠다면 설정 → 백업 · 초기화 → '불러오기 전으로 되돌리기'로 되돌립니다.

학생 서명 받기 - 수행평가 외 활동 확인 · 안내문 · 동의서 (버전 5.14)

   - 학생이 체크할 확인 문장을 고칠 수 있고, 점수 칸 없이 명단만으로도 서명을 받습니다. 안내·동의 내용은 '학생에게 전할 말'에 씁니다.

   - 큰 자료(수행평가 원본 전표, 동기화 기준본 등)는 앱을 열 때 자동으로 대용량 저장소로 옮겨집니다.

   - 아이폰·아이패드는 사파리 '공유 → 홈 화면에 추가'로 설치해 쓰세요.

새 버전 반영 (버전 5.12.1)

   - 앱을 열면 새 버전을 자동으로 확인해 '지금 업데이트' 안내가 나옵니다. 설정 → 앱 정보 → '새 버전 확인 · 업데이트'로 직접 확인할 수도 있습니다. 업데이트해도 입력한 자료는 그대로입니다.
   - 안내가 나오지 않으면 주소 뒤에 ?v=숫자 를 붙여 한 번 엽니다(예: .../teachers-life/?v=1). 브라우저의 '인터넷 사용 기록 삭제'에서 '쿠키 및 사이트 데이터'를 지우면 앱 자료가 모두 지워지니 절대 선택하지 마세요.

관찰 기록 사진 · 동영상 · 녹음 (버전 5.12)

   - 파일은 찍은 기기에만 저장되고 구글 연동·백업으로 옮겨지지 않습니다. 오래 보관할 파일은 '저장 · 보내기'로 따로 저장하세요. 학생 사진·영상·음성은 개인정보이므로 학교 지침을 따르세요.

1교시 이전 시간 · 시간 연동 · 관찰 기록 잠금 (버전 5.11)
   - 시간표 → 칸 편집 → '＋ 1교시 이전 시간 추가'(또는 시간 설정 · 학기 → '＋ 시간 추가')에서 아침활동·조례 등을 이름·시작·길이로 넣습니다. 출석 체크할 학급(담임 학급 등)을 정할 수 있고, 왼쪽 이름을 눌러 고치거나 삭제합니다.
   - 시간표에서 고른 출석 체크와 일정은 그 시간과 연결되어, 시간표 시간을 바꾸면 오늘 이후의 연결된 출석 체크(잠기지 않은 것)와 일정이 함께 옮겨집니다.
   - 출석 → 관찰 기록에서 '잠그기'를 누르면 그 날 관찰 기록이 바뀌지 않습니다. '잠금 해제'로 풉니다.

수업 메모장과 일정·알림 (버전 4.0)
   - 시간표의 수업 칸을 누르면 그 날 수업의 진도, 수업 메모, 과제, 학생 면담 약속을 적을 수 있습니다. 다음 시간에는 지난 수업 진도가 함께 보입니다.
   - 점심·방과 후 칸이나 요일을 누르면 그날 일정을 넣습니다. 1교시 이전(예: 08:00~08:50), 쉬는 시간(예: 2교시 후), 점심시간, 방과 후를 버튼으로 고를 수 있습니다.
   - 공강 시간: 일정 추가에서 그날 시간표를 보고 수업이 없는 교시가 초록색 '공강' 버튼으로 나옵니다. 연속 공강은 '5~7교시 공강'처럼 묶어서도 고를 수 있고, 수업 변동·휴강도 반영됩니다. (버전 4.7)
   - 분류: 학생 면담, 수업 준비, 수업 진도, 수행평가, 교무 업무, 부서 업무, 학생 활동, 개인 일정, 기타
   - 알림(정시~하루 전)은 앱이 열려 있을 때 울립니다. 처음에 '알림 허용'을 눌러 주세요.
   - 앱을 닫아도 알림을 받으려면 일정의 '구글 캘린더에 추가'를 누르거나, '앞으로의 일정 캘린더 파일로 보내기'로 휴대폰 캘린더에 넣으세요.

구글 로그인 · 컴퓨터와 휴대폰 연동 (버전 5.0)
   같은 구글 계정으로 로그인하면 컴퓨터의 크롬과 휴대폰에서 같은 자료로 일합니다.

   [처음 한 번] 구글 클라이언트 ID 만들기 (앱을 올린 선생님이 컴퓨터에서)

   4) 데이터 액세스 → 범위 추가: .../auth/drive.appdata 와 openid, email, profile → 저장
   5) 대상 → 테스트 사용자: 선생님 구글 계정(같이 쓸 선생님 계정도) 추가 (최대 100명)

   8) 앱 폴더의 config.js를 메모장으로 열어 googleClientId: "" 따옴표 안에 붙여 넣고 저장 → Netlify Deploys에 폴더를 다시 올리기

적용 기간 - 학년도 · 학기별 자료 (버전 5.7)
   - 설정 → '적용 기간 (학년도 · 학기)'에서 학년도와 학기를 고르면 학급 정보, 학생 명단·연락처, 수업 교사, 교직원 연락처, 평가가 그 기간 것만 보입니다. 다른 기간 자료는 지워지지 않고 보관됩니다.
   - 새 학기를 시작할 때: 자료가 없는 학년도·학기를 고르면 '다른 기간의 학급·명단 복사해 시작'(학급과 명단·연락처·교사·교직원 중 고른 것만 복사, 출석·관찰 기록은 복사하지 않음) 또는 '빈 학급 하나 만들기'를 고릅니다.
   - 설정할 학급 고르기: '학급 정보 · 문자 문구', '학생 명단 · 연락처'는 출석 화면에서 고른 학급이 기본입니다. 위쪽 '설정할 학급'에서 다른 학급을 고르면 출석 화면 학급은 그대로 둔 채 그 학급을 고칠 수 있습니다.

수행평가 점수 확인 · 학생 자필 서명 (버전 5.1)
   1) 학생 이메일 넣기: 설정 → 학생 명단 · 연락처에서 학생을 추가할 때 '이메일' 칸에 쓰거나, 이미 있는 학생을 눌러 '이메일' 칸에 입력하거나, 일괄 입력·엑셀 양식의 '이메일' 칸에 넣습니다.
      (전표 파일에 이메일 칸이 있으면 그 주소를 씁니다)
   2) 아래 메뉴 '평가·통계' → '수행평가 서명' → '전표 올리기'로 점수 파일(엑셀·CSV)을 고릅니다.
      표의 제목 줄에 학번, 이름, 이메일, 항목(과제 수행, 발표, 보고서), 총점, 의견을 칸마다 하나씩 쓰고 그 아래 줄부터 학생을 한 줄씩 입력합니다(앱에서 받은 양식 맨 위의 문서 제목·내려받은 일시 줄은 그대로 두어도 됩니다). 시트가 여러 개면 전표가 있는 시트를 알아서 고릅니다. 학교 전표 양식을 그대로 올려도 됩니다. '전표 양식 받기'에서 (1) 학급을 고르고 평가 항목을 입력하면 그 학급 학생(학번·이름·이메일)과 항목 칸이 미리 들어간 양식을, (2) '기본 양식'을 고르면 예시 양식을 받습니다. 총점 칸에는 합계 수식을 넣을 수 있습니다. (버전 5.4.1)
   3) 평가 이름, 학급, 서명 마감일, 학생에게 보여 줄 칸, 회신 받을 내 이메일을 확인하고 '평가 만들기'
      '학생에게 보여 줄 칸'은 눌러서 켜고 끕니다(✓ 표시가 켜진 칸). '(빈 칸)'으로 나오는 칸은 파일에서 값을 읽지 못한 칸이니, 엑셀에서 파일을 열어 저장한 뒤 다시 올리세요.
   4) 보내기
      - 'Gmail로 보내기': 학생마다 자기 점수만 담긴 메일이 한 번에 나갑니다. (구글 로그인 + 처음 한 번 'Gmail로 보내기' 권한 허용)
      - '메일 앱으로 한 명씩': 누를 때마다 다음 학생 메일 창이 열립니다. 권한 설정이 필요 없습니다.
      - 학생 줄의 '문자'·'링크 복사'로 이메일 없는 학생에게도 보낼 수 있습니다.
   5) 학생: 메일의 '점수 확인하고 서명하기'를 눌러 점수를 보고, 확인란 체크 → 손가락으로 서명 → '서명 완료' → '선생님께 이메일 보내기' → 메일 앱에서 보내기
   6) 선생님: 받은 메일의 링크를 누르면 앱이 열리며 서명이 자동으로 들어갑니다. 여러 통은 메일 내용을 복사해 '서명 받기' 칸에 붙여 넣어도 됩니다.
      서명 현황에서 학생별 서명 그림과 시각을 확인합니다. 보낸 뒤 점수를 바꾸면 '점수 바뀜'으로 표시되어 다시 받아야 합니다.
   7) 모두 서명하면 '엑셀 파일(서명 그림 포함)'로 올린 전표의 오른쪽 끝에 '학생 서명'·'서명 일시' 칸이 붙은 파일을 받고, 'PDF로 인쇄'로 출력합니다.
      모두 서명하지 않아도 출력할 수 있습니다. 출력 설정에서 (버전 5.2)
      - 서명 여부를 표기할 학생을 고릅니다: '모두 표기', '서명한 학생만 표기', 또는 학생별 체크. 체크를 끈 학생은 서명 칸을 비워 둡니다.
      - '서명하지 않은 학생에게 문구 넣기'를 켜면 '개별 연락을 통해 성적을 확인함'이 서명 칸에 들어갑니다. 학생 줄의 '미서명'을 눌러 학생별로 넣거나 뺄 수 있고, 문구도 고칠 수 있습니다.
   * Gmail로 보내기를 쓰려면 구글 콘솔에서 한 번 더 설정합니다.
       - API 및 서비스 → 라이브러리 → 'Gmail API' → 사용
       - 앱이 '프로덕션'이면 Gmail 보내기 권한은 구글 심사 대상이라 로그인 때 '확인되지 않은 앱' 경고가 나옵니다('고급' → '이동'으로 계속 가능).
         경고 없이 쓰려면 앱을 '테스트' 상태로 두고 쓰는 선생님 계정을 테스트 사용자에 넣으세요. '메일 앱으로 한 명씩'은 이 설정 없이 됩니다.
   * 점수는 학생 각자의 링크에만 들어 있고, 서명은 학생 메일을 통해 선생님께만 돌아옵니다. 서버에는 저장되지 않습니다.

구글 계정 추가 · 전환 (버전 5.1)
   - 설정 → '구글 로그인 · 기기 연동' → '＋ 다른 구글 계정 추가 · 전환'으로 다른 계정으로 로그인합니다.
   - 계정마다 자료가 따로 저장됩니다. 전환하면 그 계정의 자료로 바뀌고, 'OOO(으)로 전환'을 누르면 원래 계정과 자료로 돌아옵니다.

출석 체크 잠금 (버전 5.4)
   - 출석 체크를 마치면 체크 아래 '잠그기'를 누르세요. 잠긴 체크는 학생 줄을 눌러도 바뀌지 않고, 전원 출석·결석, 삭제, 시간 수정도 막힙니다.
   - 고쳐야 하면 '잠금 해제'를 누릅니다(한 번 더 확인). 잠긴 체크는 위 시간 버튼에 🔒이 붙습니다.

평가 모아 보기 · 보관함 (버전 5.4)
   - '평가·통계' → '수행평가 서명'에서 학년도, 학기, 학급, 진행 중/보관함/전체로 평가를 골라 봅니다. 평가 이름으로 찾을 수도 있습니다.
   - '＋ 직접 만들기': 학급 명단으로 평가를 만들고 앱에서 점수를 입력합니다. 총점 칸은 '자동 계산'으로 채울 수 있습니다.
   - 평가 화면: '전표 보기'(서명 그림·일시가 든 전표를 앱에서 보기), '점수 고치기', '평가 정보 수정', '평가 마치고 보관'
   - 보관한 평가는 '보관함'에서 언제든 다시 열어 전표를 보고 엑셀·PDF로 받을 수 있습니다.
   - '서명 현황 모아 보기': 고른 조건의 평가별 서명한 학생·안 한 학생과 학생별 미서명 평가를 보고 엑셀로 받습니다. 평가를 누르면 그 평가의 서명 안 한 학생 목록으로 갑니다.

학생 관찰 기록 (버전 5.3)
   - 아래 메뉴 '출석' → 날짜 아래 '관찰 기록'을 누릅니다. ('출석 체크'를 누르면 원래 출석 화면)
   - 빠른 체크: 위쪽 항목(예: 질문함)을 누른 뒤 학생 이름을 누르면 바로 기록됩니다. 여러 번 누르면 ×2, ×3으로 쌓이고, 잘못 눌렀으면 아래 '되돌리기'.
     항목을 다시 누르면 선택이 풀리고, 이때 학생 이름을 누르면 그 학생의 기록 창이 열립니다. 항목 줄은 옆으로 밀어 더 볼 수 있습니다.
   - 기록 날짜: 관찰 기록 화면의 '기록 날짜'에서 고릅니다. 고르지 않으면 오늘 날짜로 기록됩니다. 옆에 그날 기록 횟수와 누적 횟수가, 학생 이름 아래에 학생별 누적 횟수와 기록한 날 수가 보입니다. (버전 5.4)
   - 기록 창: 수업 태도·역량·특성 항목을 체크하고 메모를 적습니다. 자주 쓰는 문구를 눌러 메모에 넣을 수 있습니다.
     아래에 누적 항목(예: 질문함 5, 탐구력 3)과 지난 기록이 보이고, '누적 기록 복사'로 세부능력 및 특기사항 작성에 쓸 수 있습니다.
   - '항목 편집'에서 분류와 항목을 더하거나 지우고, ●을 눌러 좋음(초록)·보통(회색)·아쉬움(빨강)을 정합니다.
   - '관찰 기록 엑셀로 받기': 학생별 누적과 날짜별 기록이 담긴 엑셀 파일을 받습니다.
   - 관찰 기록은 공유 링크에 들어가지 않습니다. 구글 로그인으로 연동하면 컴퓨터와 휴대폰에서 같이 보입니다.

출석 체크와 통계
   - 출석 화면에서 날짜를 고르고 '＋ 체크 추가'를 누르면 지금 시간으로 새 출석 체크가 생깁니다. 횟수 제한은 없습니다.
   - 체크마다 시간과 이름(예: 출발 전)을 바꿀 수 있습니다.
   - '평가·통계' → '출석 통계'에서 기간과 학급을 고르면 학급별·일자별·학생별 출석 통계를 볼 수 있습니다.
   - '이메일 보내기'는 통계가 채워진 메일 앱을 열고, '엑셀 파일로 보내기'는 파일 2개를 첨부해 보냅니다.

연락하기
   - 연락 화면 위쪽에서 '결석 학생', '학생 골라 연락', '교사 · 교직원'을 고릅니다.
   - 결석 학생에게 전화나 문자로 연락을 마치면 '✓ 연락 완료'를 누르세요. 출결은 결석 그대로 저장되고, 연락 버튼의 숫자(연락 알림)와 한꺼번에 보내기에서만 빠집니다. 아래 '연락 완료' 칸에서 완료 시각을 보고 '완료 취소'로 되돌릴 수 있습니다. (버전 4.9)
   - '학생 골라 연락'은 출석 체크와 상관없이 원하는 학생을 골라 전화하거나 문자를 보냅니다.
   - 위쪽 학급 버튼으로 다른 학급, 여러 학급, '모든 학급'을 골라 그 학생들에게 연락할 수 있습니다. 여러 학급을 고르면 학급별로 묶여 보입니다. (버전 4.6)
   - 교직원 연락처는 설정 → '교직원 연락처'에서 등록하며, 모든 학급에서 같이 씁니다.
   - 수업 교사와 교직원은 '여러 명 일괄 입력'으로 엑셀 표를 붙여 넣거나 CSV 파일을 골라 한꺼번에 넣을 수 있습니다.

할 일 (버전 4.4)
   - 아래 메뉴 '할 일'에서 기록한 일정과 수업 메모의 과제·면담 약속을 지난 미완료, 오늘, 내일, 이번 주, 다음에로 나눠 봅니다.
   - 왼쪽 네모를 누르면 완료, 내용을 누르면 수정, 종을 누르면 알림 시간을 정합니다.
   - 기간(오늘·이번 주·앞으로 30일·전체), 분류, 중요한 것만, 완료한 것 보기로 골라 볼 수 있습니다.
   - '문자로 보내기'는 수업 교사·교직원을 골라 할 일 목록을 문자로 보내고, '이메일로 보내기'는 메일 앱을 엽니다.
   - '알림 확인'에서 휴대폰 알림이 켜져 있는지, 예정된 알림과 울린 알림을 확인하고, '알림 시험해 보기'로 알림이 울리는지 시험합니다.

학급·명단·연락처 수정 (버전 4.3)
   - 학급 수정: 출석 화면 맨 위 학급 이름 → 학급 목록에서 '수정', 또는 설정 → '학급 정보'의 '학급 수정'. 이름 바꾸기, 복사해 새 학급 만들기, 삭제를 할 수 있습니다. 이름을 바꾸면 시간표의 학급 이름도 함께 바뀝니다.
   - 학생 수정: 설정 → '학생 명단 · 전화번호'에서 학생을 누르면 학번·이름·전화번호를 고치거나, 다른 학급으로 옮기거나, 삭제할 수 있습니다. 학번을 바꾸면 출석 기록도 함께 옮겨집니다.
   - 수업 교사·교직원 수정: 각 칸에서 이름을 누르면 이름·과목(부서·직위)·전화번호를 고치거나 삭제할 수 있습니다.
   - 명단이 길면 각 칸의 찾기 칸에 이름이나 학번, 부서를 넣어 찾으세요.

명단·연락처 파일로 넣기 (버전 4.2)
   - 설정 → '명단 가져오기 · 입력 양식'에서 학생 명단, 수업 교사, 교직원 양식을 엑셀이나 CSV로 내려받습니다.
   - 양식에 입력한 뒤 학생 명단·수업 교사·교직원 연락처 칸의 '일괄 입력 · 파일 올리기'에서 '파일 올리기'로 고르면 됩니다.
   - 엑셀 파일(.xlsx)을 그대로 올려도 되고, 붙여 넣기도 계속 됩니다. 올리기 전에 미리보기로 확인합니다.
   - '예시'라고 적힌 줄과 제목 줄은 자동으로 건너뛰고, 엑셀에서 빠진 휴대폰 번호 앞자리 0도 자동으로 되살립니다.
   - 엑셀 파일 읽기는 처음 한 번 인터넷이 연결되어 있어야 합니다. 그 뒤에는 인터넷 없이도 됩니다.

백업과 예전 버전 불러오기 (버전 4.1)
   - 설정 → '백업 · 초기화'에서 '백업 파일 저장'을 누르면 모든 데이터가 파일 하나로 저장됩니다. 메일·카톡·드라이브에 보관하세요.
   - '백업 파일 불러오기'나 '명단 가져오기' 칸에 붙여 넣기로 예전 버전(출석부앱 1.x~4.x)의 백업도 그대로 불러옵니다.
   - 불러오기 전에 어떤 버전의 백업인지, 무엇이 바뀌는지(예: 1~6차 출석 → 날짜별 출석 체크, 인솔교사 → 수업 교사)를 보여 줍니다.
   - '지금 데이터와 합치기' 또는 '백업 내용으로 완전히 바꾸기'를 고를 수 있고, 잘못 불러왔으면 '불러오기 전으로 되돌리기'를 누르세요.

화면 · 글자 크기 (버전 5.6)
   - 앱이 기기 화면 크기에 맞춰 칸과 배치를 자동으로 맞춥니다. 컴퓨터처럼 넓은 화면에서는 메뉴가 왼쪽으로 가고 두 줄로 넓게 보입니다.
   - 설정 → '화면 · 글자 크기 (기기 맞춤)'에서 글자 크기, 화면 배치, 메뉴 위치, 시간표 보기를 기기마다 바꿀 수 있습니다. '모두 자동으로'로 되돌립니다.

버전 확인
   - 설정 화면 맨 아래 '앱 정보 · 버전 기록'에서 지금 버전과 바뀐 내용을 볼 수 있습니다.
   - 예전에 홈 화면에 추가한 아이콘 이름은 바뀌지 않습니다. 이름을 '교사의 생활'로 보이게 하려면 아이콘을 지우고 다시 홈 화면에 추가하세요. (입력한 데이터는 그대로 남습니다)

알아둘 점
   - 출석 체크와 명단은 각자의 휴대폰에만 저장됩니다. 서버에는 아무것도 저장되지 않습니다.
   - 한 번 연 뒤에는 인터넷이 없어도 앱이 열립니다. (문자·전화는 통신이 되어야 합니다)
   - 문자 버튼을 누르면 내용이 채워진 문자창이 열리고, 전송은 직접 누릅니다.
