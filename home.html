‘교사의 생활’은 학교 선생님의 하루 — 출석, 시간표와 진도, 수업 흐름, 수업 관찰, 평가와 학생 서명, 생활 · 상담 기록, 학생 · 학부모 · 교직원 연락 — 를 휴대폰과 컴퓨터에서 한 곳에서 관리하도록 돕는 무료 웹앱입니다. 설치 없이 브라우저로 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다. 아래 메뉴는 오늘 · 시간표 · 출석 · 연락 · 기록 다섯 가지이고, 설정은 오른쪽 위 ⚙입니다.

주요 기능

  • 오늘오늘 수업과 출석 체크 상태, 연락할 결석 학생, 서명 마감, 할 일 · 일정, 수업마다 수업 흐름(⏱)을 한 화면에. 수업 시간에는 맨 위 ‘지금 수업’ 카드
  • 시간표 · 진도컴시간 캡처 · 엑셀로 시간표 올리기, 학사일정 반영. 교과마다 진도표(엑셀 양식 받기 · 올리기)를 만들고 수업 칸에서 단원별로 마침 · 반만 · 안 함, 직접 입력, 계획과 실제 비교, 남은 수업 시간 경고
  • 수업 흐름도입 · 전개 · 정리처럼 수업 단계를 시간으로 나눠 두면 수업 중 지금 단계 · 남은 시간을 보여 주고 1분 전 · 단계가 바뀔 때 소리 · 진동으로 알림. 교과 · 차시 · 수업마다 다른 틀, 직접 설계, 수업 전 미리 보기, 켜기 · 끄기, ＋2분 · 이전 · 다음, 밀리면 남은 단계 맞추기
  • 출석출석부(격자 · 목록, 한 번 눌러 결석), 수업 관찰(빠른 체크 · 격자 보기 · 잘못 누른 항목만 빼기 · 사진 · 녹음)과 세특 초안(나이스 byte 계산), 출석 통계와 나이스 입력용 요약
  • 연락결석 학생 · 골라 연락 · 교직원 연락 · 직접 입력 — 이름이 들어간 문자 · 전화 · 메일
  • 기록평가 3단계(만들기 · 미응시 · 점수)와 학생 자필 서명(전표 엑셀 · PDF), 생활 · 상담 · 업무 · 일상 기록, 학생마다 모든 기록을 모아 보는 학생 정보
  • 수업 도구타이머(시간을 맞추고 시작 · 누를 때마다 더하기) · 발표자 뽑기 · 모둠 나누기(효과음 · 긴장감 시간 조절, 칠판 · 프로젝터 스타일)
  • 휴대폰과 컴퓨터에서 함께구글 로그인으로 내 구글 드라이브의 앱 전용 폴더를 통해 두 기기의 자료를 맞춤. 앱 잠금(PIN), 성적 · 상담을 뺀 백업

하루에 이렇게 씁니다

  1. 아침 오늘 화면에서 수업 · 할 일 · 연락할 학생 확인, 수업마다 ⏱ 수업 흐름 미리 보기
  2. 수업 시작 지금 수업 카드 → 출석 체크, 수업 흐름이 시작 시각에 맞춰 저절로 시작
  3. 수업 중 수업 흐름 알림을 따라 진행, 수업 도구 · 수업 관찰 빠른 체크, 끝나기 전 진도 기록
  4. 수업 뒤 결석 학생 연락, 수업 메모 · 진도 정리
  5. 필요할 때 평가 · 학생 서명, 생활 · 상담 기록, 학생 정보 모아 보기

About Teacher's Life (English)

Teacher's Life (교사의 생활) is a free web app for school teachers in Korea. It helps teachers manage attendance, class timetables and lesson progress (syllabus) tracking, in-class lesson flow timing (intro, development and wrap-up stages with alerts), classroom observations, lesson notes, school-calendar changes, schedules, assessment scores and student e-signatures, student counseling and school-life records, and contacting students, parents and staff — on both phone and computer.

  • All data stays in the browser storage of the teacher's own device. The app has no server, and the developer never receives user data.
  • Optional Google sign-in lets a teacher use the same data on phone and computer. The app stores one sync file in the teacher's own Google Drive application data folder (drive.appdata) and uses the account email, name and picture (openid email profile) only to show which account is signed in. It cannot access any other Drive files.
  • Google user data is used only for these features and is never sold, used for ads, or shared. Teacher's Life's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
